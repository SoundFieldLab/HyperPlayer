# New Splash

导出自我更新的画布设计 **`RYmYR` ("1. Splash · 16:9")**，尺寸已调整为 **1400 × 900**。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `splash.html` | 纯 HTML + CSS 导出，可直接在浏览器中打开。 |
| `splash-tailwind.html` | Tailwind CSS 版本导出。 |
| `RYmYR.png` | 1400 × 900 的 2x 高清位图（2800 × 1800）。 |
| `logo-mark.png` | Logo 图片资源，被两个 HTML 文件引用（`./logo-mark.png`）。 |

## 使用方式

直接用浏览器打开 `splash.html` 或 `splash-tailwind.html` 即可预览。

- 字体（Space Grotesk）通过 Google Fonts CDN 加载，需要联网。
- `splash-tailwind.html` 通过 `https://cdn.tailwindcss.com` 加载 Tailwind，需要联网。
- `logo-mark.png` 与 HTML 文件放在同一目录，请保持在一起。

## 设计尺寸

- 画布：1400 × 900
- 原始设计：1920 × 1080（16:9），本次等比缩放并垂直居中，背景层铺满 1400 × 900。
