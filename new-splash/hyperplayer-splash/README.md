# HyperPlayer — 会流动的启动页

双击 **`index.html`** 即可。整页**完全自包含**：logo 与字体都已内联为 data URI，**没有任何外链、不需要联网**。

---

## 这个目录里有什么

| 文件 | 说明 |
|---|---|
| `index.html` | **成品**。背景真的在流动（中等速度），双击打开即可 |
| `splash-static.png` | 静态参考图（pen.dev 画布导出的原始画面） |
| `build.py` | 生成脚本：从 `../splash.html`（pen.dev 导出）重新生成 `index.html` |
| `assets/` | 内联所需的素材：`logo-mark.png`、`space-grotesk-700.woff2` |

> 为什么 pen.dev 画布上看不到流动？pen.dev 是静态设计画布（没有时间轴），
> 所以**设计本身是静止的**，流动实现落在导出的 HTML 里 —— 这也是你打开 html 能看到动的原因。

## 改速度

打开 `build.py`，最上面一个旋钮：

```python
SPEED = 1.6      # 当前值（比最初的中等速度 1.0 快 60%）；想再快就 2.0，想安静回到 1.0
```

改完运行：

```bash
python build.py
```

也可以直接改 `index.html` 里 `<script>` 第一行的 `var SPEED = 1.6;`（临时试速度用）。

## 锁体的进入动画（logo + HyperPlayer）

两侧都从**接缝**（logo 与文字之间那条虚线，逻辑上位于 x≈815）后面冒出来，再反方向弹出：

| 元素 | 起始状态 | 结束 | 时长 / 延迟 |
|---|---|---|---|
| 玻璃图标块（logo） | 相对落位 **+150px**（藏在接缝里）、缩放 0.86、模糊 16px、透明 0 | 向左弹出到落位 | **1800ms** / +80ms |
| `HyperPlayer` 字标 | 相对落位 **−250px**（同样藏在接缝里）、缩放 0.96、模糊 14px、透明 0 | 向右弹出到落位 | **1750ms** / +200ms |

整个进场约 **1.95 秒**完成（logo 1.88s、字标 1.95s）。
注意：这段时长是**真实秒**，不受 `SPEED`（流体速度）旋钮影响 ——
拧快流体不会把进场动画一起拧快。

- 位移动画用 `easeOutBack(1.2)`，即到位后**约 6% 过冲再回落**（就是你说的"弹"，但幅度克制所以显得丝滑）；
  `easeOutBack` 在 2 秒尺度上会把过冲拉得很长，所以慢速下尤其要注意别把 `c1` 调大；
- 模糊是随位移一起线性收敛到 0，透明度的曲线比位移**提前一点点到位**（东西先“看得见”再稳稳停住）；
- 动画结束后脚本会把行内样式**全部清空**，所以静止状态与 pen.dev 设计稿逐像素一致（实测 2.57/255）；
- **按 `R` 键可以重播**整个进场（同时把流体也归零重跑），方便反复看。

调参：`build.py` 里的 `ENTRANCE` 表（`dx` 起点偏移、`sc` 起始缩放、`blur` 起始模糊、`dur/delay`）。

## 颜色怎么个流动法

背景不只是"整块平移"——有三组 **颜色形变对（colour morph pair）**：

| 组 | A 色 | B 色 | 周期 |
|---|---|---|---|
| Morph Center | 品红 → 紫 | 青 → 薄荷 | 16 / SPEED |
| Morph Right | 橙 → 金 | 紫罗兰 → 靛 | 20 / SPEED |
| Morph Left | 蓝 → 青 | 玫红 → 珊瑚 | 14 / SPEED |

每组里 A 与 B 完全重叠、**透明度反相呼吸**（0 ↔ 2× 基准值），
所以那片区域是**真的在换色**而不是仅仅在位移；三组周期互不相同，
任意时刻画面上的冷暖配比都不一样。实测：同一层 5 秒内透明度从 0.60 摆到 0.21。

想调形变强弱/快慢：改 `build.py` 里的 `MORPH` 表（符号、幅度、周期）。
注意成对的 A/B 必须在 `LAYERS` 里保持**完全相同的漂移参数**，否则会错位。

## 重新导出后怎么办

1. 在 pen.dev 里导出：格式 `html-css`，路径 `../splash.html`（即上一级目录的 `splash.html`）
2. 在本目录运行 `python build.py`
3. 刷新 `index.html`

`build.py` 会自动识别画布上的图层名（Color Wash / Mass Blue / Ribbon Mint …）：
新增图层不会报错，删掉的图层会被自动跳过；想调整某一层的漂移幅度，
改 `build.py` 里的 `LAYERS` 表即可（`ax/ay` 位移像素、`sc` 缩放呼吸、`rot` 旋转漂移、`t1/t2` 两个正弦周期、`op` 透明度呼吸）。

## 实现要点

- 每层两个不同周期的正弦叠加 → 运动**永不重复**，也不会整块平移，像流体而不是幻灯片。
- 所有项在 `t = 0` 时都为 0 → **第一帧与 pen.dev 设计逐像素一致**（实测差异 3.4/255，属抗锯齿级别），之后才慢慢流动开。
- 每帧只写 `transform` / `opacity`，并给图层加 `will-change` → 走 GPU 合成，不去重绘那些大半径模糊，1080p 下很轻。
- 浏览器会把被遮挡/最小化窗口的 `requestAnimationFrame` 节流到 0；脚本另外挂了一个 100ms 定时器兜底，所以在后台也不会"停住"。
- 无障碍：想尊重系统的"减弱动态效果"，把 `build.py` 里 `RESPECT_REDUCED_MOTION` 改成 `True`（默认 `False`，即始终流动）。

## 性能小提示

背景共 **18 层**在动（12 层漂移 + 3 组颜色形变），都是大半径模糊，
上面还压着一层 40% 毛玻璃（`backdrop-filter`）。
若在低端集显机器上觉得吃力，把 `LAYERS` 里几层删掉（例如 `Ribbon Aqua`、`Vein Light`、
以及一组 `Morph …`）即可，画面依然流动，负载明显下降。
