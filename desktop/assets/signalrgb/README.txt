HyperPlayer SignalRGB Dynamic Effect

Installed only through the HyperPlayer main-process IPC integration. HyperPlayer.html is an original,
self-contained Canvas 2D effect and does not use external scripts, network requests, or copied
SignalRGB effect source. The adjacent HyperPlayer.hyperplayer.json sidecar is generated at install time
and is required for ownership-safe updates and removal.

Canvas Event sender: hyperplayer
Supported events: play, pause, stop, accent, beat:0..100, theme:RRGGBB:RRGGBB,
style:<one of the twelve declared styles>, section:intro|verse|pre-chorus|chorus|bridge|outro|breakdown|drop|solo.
