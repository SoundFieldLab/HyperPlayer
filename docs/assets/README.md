# README 展示素材

此目录保存项目 [README](<../../README.md>) 使用的轻量展示图，避免依赖被 Git 忽略的本地宣传目录。

## 来源与处理

- 来源：本地宣传素材中的 8 张实机截图。
- 导出：保留完整 16:10 构图，使用 Lanczos 缩放到 1600 × 1000，再编码为 WebP（quality 88）。
- 8 张展示图合计 896,924 字节；不改动原始截图，不引入应用运行依赖。
- 文件以原素材编号命名；桌面模式原素材虽使用 PNG 扩展名，实际内容为 WebP，导出时已统一格式。

## 展示范围

- 截图用于介绍产品体验，不承诺当前版本的像素级界面一致性。
- 调音室素材为旧版深色界面，在项目说明中折叠展示并明确标注；不能据图中的标识或数值宣称第三方认证或性能。
- 原素材中的昵称、头像及天气位置按既有素材交付说明原样保留。
- 歌曲、封面及第三方商标归各自权利人所有；本说明不额外授予这些内容的使用权。
