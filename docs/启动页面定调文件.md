# Tauri 应用启动动画实现需求文档（v3）

> **v3 修订（2026-09-05，依据 UI-D87 / UI-D92 / UI-D95 / `docs/设计语言-apple.md`）**：
> 1. 渐变色改为品牌双色 Hyper Blue `#3F55F9` → Pulse Orange `#FF761C`（废除蓝紫渐变）
> 2. 动画库统一 Motion + CSS Keyframes / Web Animations API（不引入 GSAP）
> 3. 毛玻璃参数对齐 chrome 材质基线 `blur(20px) saturate(1.8)`
> 4. 新增字体规范（Segoe UI Variable Display；得意黑仅保留在 LOGO 图片资产）
> 其余规格（随机相位、弹性入场、单窗口条件渲染、8s 超时）沿用 v2。

## 1. 任务概述

请为当前的 Tauri 项目实现一个**自定义启动引导页（Splash Screen）**。该页面需要在应用主界面加载完成前展示，并在加载完成后平滑过渡到主界面。

## 2. 技术栈约束

- **框架**: Tauri (v2.x)
- **前端**: 根据项目现有配置自适应，若无则使用原生 HTML/CSS/JS
- **动画库**: 统一使用 Motion（motion/react）+ CSS Keyframes / Web Animations API；**不引入 GSAP**（UI-D68/UI-D96）
- **窗口管理**: Tauri Window API (`@tauri-apps/api/window`)

## 3. 视觉设计规范

### 3.1 布局结构

- 启动页容器占满整个窗口 (`100vw × 100vh`)，深色/品牌色背景
- 内容区域水平垂直居中
- **核心容器**：一个圆角矩形毛玻璃背景板，内部采用 Flexbox 横向排列 `[LOGO] [间距] [项目名称]`
- LOGO 与名称之间**无任何可见分隔线**，仅保留适当间距（建议 16–24px）

### 3.2 毛玻璃背景板

| 属性   | 值                                            |
| ------ | --------------------------------------------- |
| 形状   | 圆角矩形，border-radius: 16–20px              |
| 背景   | `rgba(255,255,255,0.08)` 或适配主题的半透明色 |
| 模糊   | `backdrop-filter: blur(20px) saturate(1.8)`（对齐 chrome 材质基线，UI-D95） |
| 边框   | `1px solid rgba(255,255,255,0.12)` 增加层次感 |
| 内边距 | 水平 40–56px，垂直 24–32px                    |
| 阴影   | 柔和扩散阴影，增强悬浮感                      |

### 3.3 项目名称 — 流动渐变文字（重点）

- **渐变色范围**：Hyper Blue (`#3F55F9`) → Pulse Orange (`#FF761C`)（UI-D87 定稿，品牌双色；禁止蓝紫渐变）

- **渐变方向**：从左到右 (`linear-gradient(90deg, ...)`)

- **文字裁剪**：`background-clip: text; -webkit-text-fill-color: transparent`

- 流动效果要求

  ：

  - 渐变并非静态，而是像水流一样在文字上持续缓慢流动
  - ⚡ **关键：每次启动时流动的相位/速度/方向必须有差异**，避免重复感
  - 实现方式建议：通过 JS 在每次挂载时随机生成 CSS 变量（如 `--flow-offset`, `--flow-duration`, `--flow-direction`），注入到 keyframes 中
  - 流动应柔和自然，周期建议 3–6s 之间随机，不要过快

### 3.4 LOGO

- 固定尺寸，与文字高度视觉对齐
- 无需特殊着色，保持原始样式

### 3.5 字体（UI-D92）

- 项目名称使用 `Segoe UI Variable Display`，字重 600，`letter-spacing: -0.02em`；中文 fallback 思源黑体
- 得意黑不用于启动页 UI（仅保留在 LOGO 图片资产内）

## 4. 动画时序规范

```
时间轴 (ms):  0        300       500       700      1000     1400+
             |----------|---------|---------|---------|---------|
毛玻璃框:    [淡入+微缩放]
LOGO:                  [←弹性滑入]
名称:                            [弹性滑入→] + [渐变流动开始]
停留:                                              [保持+流动持续]
退场:                                                       [整体淡出↑]
主界面:                                                      [显示]
```

### 4.1 入场动画

1. **毛玻璃背景板**: `opacity(0) scale(0.92)` → `opacity(1) scale(1)`，400ms，ease-out
2. **LOGO**: `translateX(-50px) opacity(0)` → `translateX(0) opacity(1)`，400ms，弹性缓动 `cubic-bezier(0.34,1.56,0.64,1)`，延迟 200ms
3. **项目名称**: `translateX(50px) opacity(0)` → `translateX(0) opacity(1)`，400ms，弹性缓动，延迟 350ms；同时渐变流动动画开始播放

### 4.2 退场过渡

- 收到「加载完成」信号后，整个容器 `opacity:1→0` + `translateY(-20px)`，400ms
- 退场结束后销毁/隐藏启动页，显示主界面

## 5. Tauri 集成要点（关键）

### 5.1 窗口初始化

> ⚠️ 避免启动白屏闪烁

- `tauri.conf.json` 主窗口 `visible: false`
- 推荐：**单窗口 + 条件渲染** splash 组件（避免多窗口切换闪烁）
- 若用独立 splash window，确保尺寸与主窗口一致且无边框

### 5.2 加载完成信号

```rust
// Rust 侧：初始化完成后
app.emit("splash:complete", ()).unwrap();
// 前端侧
import { listen } from '@tauri-apps/api/event';
await listen('splash:complete', () => {
  playExitAnimation().then(() => setShowSplash(false));
});
```

### 5.3 安全机制

- 最大超时 8s，强制进入主界面
- 退场期间 `pointer-events: none`

## 6. 交付要求

1. 完整启动页组件代码（含毛玻璃样式、流动渐变逻辑、弹性动画、事件监听）
2. **流动渐变的随机化实现代码**（JS 生成随机 CSS 变量的部分）
3. `tauri.conf.json` 窗口配置修改片段
4. Rust 侧 `splash:complete` 事件发送位置建议
5. 所需第三方依赖列表（如有）

## 7. 验收标准

-  启动无白屏/黑屏闪烁
-  毛玻璃背景板模糊效果正常，圆角与阴影美观
-  项目名称呈现蓝→紫渐变，且有明显的水流般流动感
-  **连续多次启动，流动效果的节奏/相位可感知地不同**
-  LOGO 和名称弹入有弹性效果，非匀速线性
-  LOGO 与名称之间无多余分隔元素，间距协调
-  加载完成后过渡平滑无跳变
-  超时保护正常工作
-  窗口缩放时布局保持居中
