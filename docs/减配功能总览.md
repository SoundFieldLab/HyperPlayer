## 附录 B：明确「不存在」的功能（避免误列）

- **系统托盘图标 / 右键菜单** —— 全仓库无 `new Tray`。`taskbarTray*` 只是用 Win32 `TrayNotifyWnd` 测量托盘区左缘坐标来停靠迷你播控条。
- **开机自启** —— 无 `setLoginItemSettings` / auto-launch 任何代码（跨 cjs/mjs/ts/tsx/json/md 零匹配）。
- **SQLite** —— 全仓库无 sqlite / better-sqlite3 引用（缓存全为 IndexedDB + 内存 LRU + 文件）。
