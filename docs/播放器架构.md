# HyperPlayer 播放器架构（详细设计）

> 定调日期：2026-09-05。本文是 `docs/架构基线.md` 的细化：模块职责、依赖规则、状态机与保险机制，粒度以"可直接开工"为准。冲突时以本文为准并回写基线。

## 2. 依赖规则（强制）

1. **单向依赖**：UI → store → service → infra → Tauri 插件。UI 组件禁止直接 import `@tauri-apps/*` 插件 API，一切原生能力经 infra 薄封装；单测因此全程用 fake，不碰 Tauri。
2. **服务间无环**：services 可互相调用但禁止循环依赖；PlayerController 是唯一允许广泛调用他家的枢纽（SessionService/StreamCacheService/HseController/QueueController）。
3. **worklet 边界**：主线程与 AudioWorklet 只经 messagePort 传协议化消息（参数帧/遥测帧），不共享可变对象、不走 React state。
4. **切片纪律**：每个 zustand 切片独立文件；高频态（position/currentWordIndex 等）以帧级写入，消费端必须窄选择器。

## 3. 状态机

### 3.1 PlaybackStateMachine（播放核心）

状态：

| 状态 | 含义 | 进入条件 |
|---|---|---|
| `idle` | 无曲目 | 启动/清空队列 |
| `resolving` | 音源解析中（权益校验/降级链/直链获取） | LOAD |
| `buffering` | 元素已挂 src，等待 canplay | RESOLVED |
| `ready` | 可播放（paused） | CAN_PLAY / PAUSE |
| `playing` | 播放中 | PLAY |
| `error` | 终态错误（带 taxonomy） | 见下 |

事件与迁移：

```
idle       --LOAD-->            resolving
resolving  --RESOLVED-->        buffering
resolving  --FAIL/超时12s-->    error(SOURCE_RESOLVE_FAIL|NETWORK|…)
buffering  --CAN_PLAY-->        ready
buffering  --ERROR/超时12s-->   error(DECODE|NETWORK)
ready      --PLAY-->            playing
playing    --WAITING-->         buffering(标记 stalledFrom)
buffering  --stalled>20s-->     error(STALLED_TIMEOUT)
playing    --PAUSE-->           ready
playing    --ENDED-->           （不进 error）→ QueueController 决策
                                     单曲循环 → 重播当前
                                     否则 → next()：有 → LOAD；无 → ready
error      --RETRY/NEXT/LOAD--> 对应状态
```

错误 taxonomy（对齐 UI-D28 的区分要求）：`SOURCE_RESOLVE_FAIL`、`NETWORK`、`DECODE`、`FILE_MISSING`、`ENTITLEMENT_LOCKED`（权益缓存锁定）、`TRIAL_RESTRICTED`（试听限制）、`DEVICE_FAIL`、`STALLED_TIMEOUT`。每种有独立文案与恢复动作；**错误不整队清空**，标记当前项不可用 + 可自动跳下一首（设置可关）。

自动恢复：`resolving` 阶段网易云源走 song/url **音质降级候选链**（vendor 语义），链尽才落 error。看门狗：resolving 12s、stalled 20s。

不变量：同一时刻**只有一个 audio 元素 active**；状态迁移由元素原生事件驱动（play/pause/waiting/playing/canplay/ended/error）+ 命令（LOAD/PLAY/PAUSE/SEEK/NEXT/PREV），命令在非法状态为 no-op 并记录日志。

### 3.2 QueueController（双区队列 + 播放模式）

状态 = `当前曲 + 接下来播放[] + 当前上下文[] + 模式 + 指针`。

命令：`playNow / playNext / append / remove / move / clearNext / clearAll / setMode`。

不变量：
- 随机模式生成**稳定洗牌序列**（返回上一首按实际历史，不重抽）；"接下来播放"永不参与洗牌。
- playNow 换上下文时默认保留临时区（UI-D43，设置可改）。
- clearNext 不动上下文；clearAll 是独立显式动作。
- 队列跨域混排，每项带来源/权益/缓存状态。

播放模式四态循环（UI-D44）：顺序 → 列表循环 → 单曲循环 → 随机。

### 3.3 SessionService 状态机（网易云会话）

```
anonymous ⇄ qrWaiting ⇄ qrScanned ⇄ loggedIn
    ▲            │800 过期→自动重取码     │
    └── logout / tokenInvalid ◄──（全局 API 拦截器）
```

- **tokenInvalid 全局拦截**：任意协议调用发现会话失效 → 统一事件 → 降级匿名 + 局部提示，不炸页面。
- QR 轮询无次数终止（沿用旧版经验：轮询永不主动断 + 800 过期自动重取），仅用户取消或登录成功停止。
- Cookie/凭据只在 stronghold；UI 永不显示/编辑原始 Cookie。

### 3.4 ScanMachine（本地曲库）

`idle → scanning(文件夹队列+进度) → summarizing → done | paused | cancelled`。

- 增量：mtime 未变跳过；Worker 内执行遍历+music-metadata 解析。
- 每文件夹**原子提交**（SQLite 事务）：中断时已提交保留，可恢复续扫。
- 状态上报侧栏状态中心（UI-D29 语义）。

### 3.5 StreamCacheService（缓存）

单曲任务：`queued → fetching(进度) → verifying(权益) → ready | locked | failed(重试3次)`。

全局 CacheManager：
- 容量预算（默认值 M0 定，设置可调）+ 最近播放 LRU 淘汰循环。
- **权益缓存每次播放前重验证**（账号/权益/权限）；失败 → `locked`：文件保留、不可播放、优先淘汰（CONTEXT 锁定缓存语义）。
- 专辑补全调度后置于缓存核心之后（低优先级空闲任务）。

### 3.6 HseController / AudioContext 生命周期

- HSE host：`detached → attaching(worklet 加载) → attached(params) ⇄ bypassed`。
- AudioContext：`absent →(首次用户手势) running ⇄ suspended`；`setSinkId` 切设备失败保持原设备 + 提示（UI-D85）。

## 4. 关键数据流走查

### 4.1 点播一首网易云歌

```
点击 → playback action → PlayerController.LOAD
  → SessionService 权益/会话校验
  → 已缓存？ LocalFileSource(convertFileSrc, asset 协议)
    未缓存？ song/url 降级链 → NeteaseStreamSource（<audio> 直链直播）
            + StreamCacheService 异步流式写盘（plugin-http → plugin-fs 分块）
  → 元素 CAN_PLAY → ready → PLAY → playing
  → rAF 循环读 active 元素 currentTime → 写 store.position（帧级）
      进度条/歌词窄选择器订阅渲染
  → LyricsTimeline 从 IndexedDB/协议取歌词 → 解析成逐字轴 → store.currentWordIndex
```

### 4.2 切歌（NEXT）

```
NEXT → 状态机离开 playing（旧元素保持出声）
     → 新曲 resolving → buffering → canplay
     → 切换 active 元素（双元素交替，旧元素转为 B 槽复用）
     → 队列指针推进 → 预取：下一曲直链预解析 + 缓存流提前写
```

### 4.3 扫库

```
添加文件夹 → ScanMachine.scanning → Worker 遍历+解析 → 每文件夹 SQLite 事务提交
→ 进度写 store → 状态中心显示 → done（汇总新增/更新/失败）
```

## 5. 保险机制（分层护栏）

| 层 | 机制 |
|---|---|
| 音频链 | 三级降级：worklet 加载失败 → ScriptProcessor 路径（HSE host `mode:'auto'`）；DSP 运行异常 → **全局旁路直通**（宁无效果不出不了声）；设备切换失败 → 回退原设备 |
| 音源 | 音质降级候选链；文件缺失标记不可用 + 跳过；看门狗 resolving 12s / stalled 20s |
| 会话 | tokenInvalid 全局拦截降级匿名；QR 过期自动重取；凭据仅 stronghold |
| 缓存 | 写入失败重试 3 次后标 failed 不阻塞播放；容量预算 + LRU；SQLite WAL |
| 数据 | 设置 schema 版本迁移；SQLite schema 版本表；队列持久化 2s 防抖 + 退出强写；崩溃恢复**恢复队列但保持暂停**（UI-D76） |
| UI | React 根 ErrorBoundary + 域级边界；unhandledrejection 捕获 → 日志环形缓冲（最近 N 条可导出）；错误局部呈现不整页覆盖（UI-D28） |
| 性能 | 高频态窄选择器；窗口隐藏时 rAF/分析帧降频；IndexedDB 失败降级内存 |

## 6. 测试边界

- 服务层/状态机：vitest + infra fake（无 Tauri），状态机以事件序列表驱动测试。
- 音频子系统：HseController/QueueController 用 fake 元素（鸭子类型，HSE host 本身支持 stub）；HSE 行为锁走 vendor 冻结向量回归。
- 组件：胶囊坞/歌词/导航栈关键组件测试。
- E2E：tauri-driver WebDriverIO 行为流；视觉人工验证（UI-D88）。

## 7. 开放点与默认值（实现时如无异议按默认执行）

| 开放点 | 默认值 |
|---|---|
| 缓存容量预算默认值 | 5 GB（设置可调，M3 定稿） |
| 看门狗阈值 | resolving 12s / stalled 20s |
| 队列持久化防抖 | 2s |
| 切歌过渡 | MediaElement 阶段不承诺无缝，先即时硬切；体验不达标进 PCM 闸门评估 |
| 日志环形缓冲 | 最近 500 条，设置里可导出 |

## 8. 补充功能（未实现项登记，2026-09-05）

M0–M5 后端主干之外的缺口全量登记见 `docs/后端补充功能规划.md`（54 项，P0–P3）。
本节只列与本文规格书直接相关的未实现项及其与既有条款的关系：

- **倍速播放（playbackRate）**：§3.1 状态机与 §4.1 走查未覆盖；变速不变调需评估 HSE 时间伸缩能力（vendor 可选依赖 signalsmith-stretch）。
- **切歌淡入淡出**：§4.2 为"旧元素出声至新曲 canplay 硬切"；音量走输出增益（§5 音频链）——需新增 per-element 淡变通道，不触碰 DSP 参数。
- **A-B 区间循环 / 睡眠定时器**：§3.1 事件表无 AB_LOOP / TIMER 事件；需新增状态与调度。
- **单曲断点续播**：§5 数据层"队列持久化"覆盖队列级位置，未覆盖每曲 position 持久化。
- **设备热插拔**：§3.6 setSinkId 为主动切换；缺 `devicechange` 被动监听与迁移策略。
- **私人 FM 流模式 / 心动模式**：§3.2 QueueController 双区模型未含 FM 无限流与智能插播策略（接口已有 playmode/intelligence 与 personal_fm 路由）。
- **歌词多轨（翻译/罗马音）与 offset（已实现，2026-09-05 B1）**：parseLrc 解析 [t:]/[r:] 独立行与行内标签（同时间合并进主行）；LyricsTimeline.setOffsetMs 查询平移；settings v4 lyricOffsetMs/perTrackLyricOffset（lyricOffsetFor 回落）。本地 .lrc 绑定、在线歌词匹配、positionAt 反向查询仍缺。
- **显式下载队列 / 封面链路 / 文件夹监听 / CUE / 标签编辑**：§3.4 ScanMachine 与 §3.5 StreamCacheService 均无对应业务；封面与下载属曲库/缓存域扩展。
- **最近播放（已实现 #48，2026-09-05 B1）**：play_history 表 + PlayHistoryService（§5 数据层扩展）；听歌统计/年度报告仍缺（record 路由为在线数据）。
- **单实例 / 托盘 / 通知（已实现，2026-09-05 B1）**：single-instance 插件注册 + JS 聚焦转发（载荷透传，文件打开 #41 留待后续）；TrayService（UI-D77 菜单 + closeBehavior=minimize 隐藏到托盘）；NotificationService（切歌通知默认关）。文件关联 / 拖拽播放 / i18n / 诊断导出仍缺。
- **半截缓存文件校验**：§5 缓存层"写入失败重试 3 次"未覆盖崩溃中断文件的检测/清理。
- 与 UI-D84 冲突项（桌面歌词/迷你模式）恢复模型见架构基线 §10；SMTC v1 缺席并记录（官方插件集无 media-session，媒体键经全局快捷键回退）；自启/更新已实现（AutostartService / UpdateService）。
