`architecture-review-<YYYYMMDD-HHMMSS>.html`。本文件保存候选的**稳定编号与状态**，让
`/implement 0X` 有明确目标。

## 使用规则

- `/implement 0X` 前先查本表；编号不存在时**停下来问**，不要临时发明一个候选。
- 新报告落地后，把候选摘要追加到本文件，并保留报告文件名与日期。
- 候选完成后补上 commit 与回归测试名，方便下一次审查跳过已完成项。
