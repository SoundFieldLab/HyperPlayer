## 0. 当前形态总览

| 项 | 值 |
|---|---|
| 平台形态 | **仅 Windows 桌面（Electron）**。Android TV 已剥离 |
| 音乐平台 | **4 个**：网易云 / QQ / Apple Music / Spotify（另有独立的「B站看歌」） |
| 界面模式 | **4 种**：简约 `minimal` / 传统 `traditional` / 探索 `explore` / 桌面 `desktop` |
| 歌词显示模式 | **4 种**：现代 `modern` / 沉浸 `immersive` / 看歌 `video` / PV `pv` |
| 音效引擎 | **仅 HSE（v3）**，14 级主链 + 第 15 级空间音频 |
| 过渡策略 | **Fixed Crossfade**（恒为）+ gapless 无缝 + albumGapless 专辑无缝 |
| 端口 | 3000 Vite / 3001 后端 / 18790 Apple bridge |
| 运行依赖 | **无内置 Python**。仅 Apple 播放面可选依赖系统 Python + pywebview |
| 测试 | 145 文件（144 通过 + 1 跳过）/ 1292 用例（1286 通过 + 5 跳过 + 1 todo） |

**与 1.0 的差异**：删除 128,732 行（603 文件），工作树 270MB → 89MB。移除内置 Python 运行时（安装包 −400~650MB）、Beat This 模型（−78MB）、离线 wheels（−106MB）、Android TV、汽水/酷狗音源、音效引擎 v1/v2、5 种歌词模式、Folia/Diorama（−63k 行）、DG_LAB 插件、AirPlay、分轨、遥控器、代理管理、设备授权、爱发电、Smart AutoMix 等。

| 内置场景 | **11 个**：流行 pop / 增强 enhanced / 爵士 jazz / 舞曲 dance / 古典 classical / 现场 livehouse / 录音棚 studio / 温暖 warm / 浩渺 dts / 悠扬舞台 vocal-stage / 深夜低音 night-bass | `src/engine/ScenePresets.ts:19-31` |
