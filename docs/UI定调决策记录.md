# HyperPlayer UI 定调决策记录

> 本文记录 2026-08-30 开始的 UI 定调会话。依据：`docs/UI调研报告/` 三份报告、现行 D21 Tauri 2 架构，以及 design-taste-frontend、high-end-visual-design、frontend-design、ui-ux-pro-max、shadcn、web-design-guidelines、frontend-design-review。
>
> 工作约束：一次只确认一个设计分叉；不写 UI 代码；结论随问随记。

## 设计判断

HyperPlayer 是供重度音乐用户长期使用的 Windows 桌面产品，不是营销页。目标气质暂定为“安静的专业音频工具 + 有温度的音乐内容”。初始设计拨盘：设计变化 6 / 动效 6 / 信息密度 7，后续可随决策修订。

## 已定

### UI-D1 · 产品主场：双内容域模式，默认网易云（2026-08-30）

- 产品存在两个一级内容域：**网易云模式**与**本地模式**
- 默认启动进入网易云模式，首页优先呈现在线推荐、歌单、榜单、继续聆听和账号内容
- 本地模式集中承载本地曲库、文件夹、专辑、艺术家和扫描状态
- 模式切换只改变浏览首页、导航项目和内容查询域；**不能中断当前歌曲、播放队列、歌词、缓存任务或 DSP 状态**
- 播放队列是跨模式共享的：本地歌曲与网易云歌曲允许在同一队列中存在，但必须明确显示来源、权益和缓存状态
- DSP 是跨模式的全局播放能力，不从任何模式中消失；入口层级后续单独确定
- 网易云模块被禁用、不可用或用户未登录时，本地模式仍构成完整播放器，应用不得退化为空壳

### UI-D2 · 内容域切换器：侧栏顶部双段切换（2026-08-30）

- 位于左侧栏顶部、产品标识下方，显示“网易云 / 本地”两个互斥段
- 切换后，侧栏导航项目和主内容首页一起替换；不是简单跳转两个普通页面
- 控件必须持续显示当前内容域，并支持键盘左右键切换
- 模式切换不影响共享播放坞、队列、歌词、缓存任务和 DSP
- 禁止将切换器隐藏进头像菜单、品牌下拉或设置页

### UI-D3 · 全局播放器：可展开播放坞（2026-08-30）

- 默认状态为底部常驻播放坞，跨网易云/本地模式、页面和导航保持可见
- 播放坞承担高频控制：封面与歌曲信息、播放/暂停、上/下一首、进度、音量、队列入口；具体控件取舍后续细化
- 点击封面或歌曲信息后，从播放坞连续展开为沉浸播放层；不是跳到割裂的独立路由
- 展开/收起期间当前播放、队列、歌词时间轴、DSP 和缓存任务持续不变
- 队列与 DSP 可作为沉浸层中的辅助面板呼出，不与主视觉争夺常驻空间
- 窄窗口下播放坞允许精简次要信息，但核心控制和展开入口必须保留

### UI-D4 · 展开播放层：封面与逐字歌词双主角（2026-08-30）

- 宽窗口下采用双主角构图：大尺寸专辑封面与实时逐字歌词共同构成主要视觉，不让控制面板或 DSP 仪表抢占中心
- **封面氛围场**：使用当前专辑封面放大、裁切和强模糊作为全屏背景来源；背景随歌曲切换做平滑过渡，不使用无关的通用渐变或装饰光球
- 在模糊封面背景之上覆盖一层克制的半透明材质，用于压低背景细节、保证歌词和控件对比度；这是 WebView2 上的毛玻璃近似，不宣称为原生 Liquid Glass
- 毛玻璃只用于播放层的整体环境或少量真正悬浮的控制表面；禁止多层玻璃卡片嵌套、遍地 blur、霓虹外发光、粒子雨和无意义流光
- 默认构图由 UI-D16 细化：左侧约 42% 封面、右侧约 58% 左对齐歌词；窄窗口改为上下结构
- DSP 可视化只允许成为低对比背景层或按需面板，不得覆盖歌词可读性或抢过封面
- 必须提供降低透明度/关闭动态背景选项；低性能、节能或减少动效模式下退化为封面主色的静态实色/渐变背景

### UI-D5 · DSP 层级：一级工作台 + 播放坞快捷面板（2026-08-30）

- 左侧栏固定“音效”一级入口，不随网易云/本地内容域切换而消失；进入完整 DSP 工作台
- 完整工作台承载效果链排序、参数编辑、预设、A/B、全局旁路和实时分析；具体效果控件待 D16 清单确定
- 底部播放坞提供当前 DSP 预设、启用/旁路状态和快捷入口；快捷面板只放高频参数，不复制完整工作台
- 展开播放层只显示当前预设/旁路状态及克制的真实音频可视化，不常驻完整参数矩阵
- DSP 状态跨内容域、页面、播放层展开/收起保持连续；切歌时是否切换曲目专属预设另行决定
- 不将 DSP 藏在设置页，也不让完整 DSP 面板全局常驻占用浏览空间

### UI-D6 · 网易云默认首页：继续聆听优先（2026-08-30）

- 默认首页首要任务是让用户快速恢复上一次聆听，不是展示尽可能多的运营内容
- 内容顺序：继续聆听/最近播放 → 每日推荐、私人 FM、新歌等高价值入口 → 推荐歌单、榜单、专辑与频道
- 已登录时使用账号个性化内容；匿名时以公开推荐、新歌、榜单替代，不出现空洞的登录墙首屏
- 不采用无限混合信息流，不把歌曲、歌单、MV、动态和评论无差别堆叠
- 横向内容轨道、榜单预览和封面网格必须有不同的信息节奏，避免连续同尺寸卡片
- 首页不承载评论、消息、歌单管理和复杂账号操作，这些放到明确的详情页或个人区域

### UI-D7 · 网易云一级导航：5 项聚合 + 高度自定义（2026-08-30）

- 默认一级项：首页、搜索、音乐库、发现、最近播放
- 音乐库聚合我的歌单、收藏内容与云盘；发现聚合榜单、新歌、MV、DJ/电台等公开浏览能力
- 音效工作台是跨内容域固定入口，不属于网易云模式的 5 项；账号、消息和设置位于侧栏底部固定区
- 设置中允许：拖拽排序、隐藏/显示默认入口、从审核过的二级功能池固定额外入口（如 MV、云盘、私人 FM、榜单）
- 结构锚点不可被全部移除：内容域切换器、至少一个内容入口、音效、当前播放、设置始终可达；隐藏所有入口时阻止保存并说明原因
- 提供一键恢复默认布局；自定义只改变导航展示，不改变路由 ID、快捷键、权限或数据来源
- 新增入口使用统一图标和命名，禁止用户创建任意 URL 或通用网络入口

### UI-D8 · 本地模式首页：曲库概览 + 最近活动（2026-08-30）

- 本地首页与网易云首页共享“继续聆听”作为首要任务，但后续内容改为本地资产而非在线推荐
- 默认内容顺序：继续聆听 → 最近新增 → 常听专辑/艺术家 → 本地播放列表 → 扫描状态与存储概览
- 默认导航：概览、歌曲、专辑、艺术家、文件夹、播放列表；同样允许按 UI-D7 在设置中排序、隐藏和固定审核过的入口
- “添加音乐文件夹”和扫描异常必须显著可达，但属于工具动作，不占据正常有内容时的首屏视觉中心
- 网易云与本地共用封面网格、歌曲列表、专辑/艺术家详情和播放交互；用来源、权益和缓存状态区分数据，不维护两套视觉系统
- 空曲库时进入专用空状态，直接引导添加文件夹和理解扫描范围，不显示伪造推荐内容

### UI-D9 · 视觉人格：明亮柔和消费产品 + 克制玻璃材质（2026-08-30）

- 全局人格以明亮、柔和、安静、精致为主，同时保留桌面曲库与专业音频工具所需的信息效率；借鉴 Apple 的内容优先和层级克制，不仿制 Apple 品牌
- 基础界面使用冷中性明亮表面，专辑封面是主要情绪色来源；封面动态取色只进入播放层及其过渡，不改变正文、焦点、危险操作和全局导航色
- 玻璃仅用于真正具有覆盖/悬浮关系的区域：展开播放层环境遮罩、覆盖滚动内容的播放坞、弹出面板、封面上的少量浮动控制
- 侧栏、普通内容卡片、歌曲列表、曲库表格和 DSP 参数区禁止玻璃化；同一区域最多一层 backdrop blur，禁止玻璃套玻璃
- 不使用装饰光球、霓虹外发光、粒子雨、持续满屏频谱和通用 AI 紫蓝渐变；普通层级依靠表面色、留白、对齐和少量分隔线建立
- 几何基线：普通控件 6px，内容项与工具面板最多 8px；胶囊只用于内容域分段器、筛选器和少量明确动作；专辑封面保持方形比例
- 普通内容和控件默认无阴影；浮层只使用一档柔和阴影，不使用黑色硬投影
- Windows 字体优先 `Segoe UI Variable, Segoe UI, system-ui, sans-serif`，不分发或假冒 SF Pro；正文 14-16px，页面标题 24-32px，主要字重 400/600，中文与正文 letter-spacing 为 0
- 玻璃近似基线：亮色半透明表面约 78% 不透明度、16px blur、135% saturation、单层半透明边界；参数只是设计起点，需实机测 WebView2 性能与可读性
- 必须提供降低透明度、关闭动态背景和减少动效；不支持 backdrop-filter、节能、低性能、窗口失焦或 Windows 高对比模式下退化为高不透明实色表面
- 正文对比度至少 WCAG AA 4.5:1；大文字/图标至少 3:1；键盘焦点使用清晰 2px 焦点环

### UI-D10 · 主题策略：明亮默认 + 完整双主题（2026-08-30）

- 首次启动默认明亮主题，稳定呈现 UI-D9 的明亮柔和产品人格；UI-D13/D15 分别覆盖 UI-D9 的字体与几何初始建议
- 设置提供三个互斥选项：明亮、暗色、跟随 Windows；选择即时生效并持久化
- 暗色主题是完整设计，不是简单反色；需保持与明亮主题相同的信息层级、品牌识别和 WCAG 对比度
- 展开播放层可依据封面形成局部明暗氛围，但不会改变用户选定的全局主题或让曲库/DSP 工作界面随曲目闪变
- 系统主题变化只在“跟随 Windows”模式下触发；切换使用连续但克制的颜色/透明度过渡
- 高对比模式、降低透明度、减少动效等系统偏好优先于主题视觉效果

### UI-D11 · 色彩系统：蓝橙双色品牌 + 可选局部封面动态色（2026-08-30）

- 固定品牌色由用户指定：Hyper Blue `#3F55F9` 与 Pulse Orange `#FF761C`
- 双色是品牌资产，但不得在同一控件或同一视觉层级中竞争；每个界面状态必须有明确主色与辅助色角色，具体职责下一题确定
- 提供“封面动态色”功能开关；用户可启用、关闭，设置需持久化
- 动态色仅进入允许的页面/区域：展开播放层的封面氛围场、与当前曲直接关联的进度高光或少量背景表面
- 动态色不得覆盖全局导航、键盘焦点、错误/警告/成功语义色、DSP 参数含义和危险操作；这些保持稳定令牌
- 动态色必须经过亮度、饱和度和对比度校正，不直接使用封面原始主色；明暗主题分别生成可访问的派生值
- 关闭动态色、降低透明度、高对比模式、封面缺失或取色失败时，回退到固定品牌色与中性表面
- 网易云红只表达来源、红心或网易云专属语义，不进入 HyperPlayer 品牌双色体系

### UI-D12 · 品牌双色语义：蓝交互 / 橙播放（2026-08-30）

- Hyper Blue `#3F55F9` 是主交互色：导航选中、主要按钮、链接、分段器选中、键盘焦点和设置确认
- Pulse Orange `#FF761C` 是播放能量色：正在播放、播放状态高光、音频进度关键状态、DSP 激活和与声音实时活动直接相关的反馈
- 普通进度轨道可使用蓝色或中性色；橙色只在“当前正在发生的音频活动”上出现，避免全局橙色过载
- 禁止把蓝橙合成通用渐变按钮、渐变标题或大面积装饰背景；双色应通过语义并置形成品牌，而不是渐变混色
- 橙色不承担警告/危险，蓝色不覆盖信息/成功/错误等系统语义色；语义状态有独立可访问令牌
- 网易云红继续只表达网易云来源与红心语义

### UI-D13 · 字体体系：得意黑塑造品牌，思源黑体承载内容（2026-08-30）

- 应用内置字体必须允许随 Apache-2.0 开源桌面应用重新分发；字体许可证、版权文件和第三方声明必须随安装包保留
- **得意黑（Smiley Sans）作为品牌/展示字体**：用于 HyperPlayer 品牌名、页面与分区标题、播放层强调文案、空状态标题和少量关键数字；它是界面气质主体，但不覆盖高密度信息
- **思源黑体（Source Han Sans SC）作为内容/UI 字体**：歌曲名、歌手、专辑信息、导航、列表、设置、正文、按钮和输入控件均使用中性字形，保证长时间扫描效率
- **歌词使用思源黑体**：主歌词、逐字 token、翻译和罗马音使用同一家族，只通过字号、字重和透明度分层；逐字高亮过程中不得切换字体或字重导致字宽抖动
- 日文/假名按思源黑体覆盖情况补 Noto Sans JP / Yu Gothic UI；技术数值、时间、码率和 DSP 参数使用开源 Cascadia Mono
- fallback：`Segoe UI Variable` / `Segoe UI` / `Microsoft YaHei UI` / `system-ui` / `sans-serif`；缺失内置字体时布局仍必须可用
- 正文 14-16px，辅助信息最低 12px；主要字重 400/600；中文与正文 letter-spacing 为 0
- 旧参考项目没有统一字体策略，也未内置得意黑；其各页面系统字体栈仅作为可读性参考，不继承其不一致做法

### UI-D14 · 图标体系：Phosphor Regular + Fill 双态（2026-08-30）

- 全应用只使用 Phosphor Icons，不与 Lucide、Tabler、Fluent 或手绘 SVG 图标混用
- 默认使用 Regular 线型；当前播放、收藏、选中、固定等需要强化状态时切换同一图标的 Fill 变体
- 统一 weight 与视觉尺寸，避免同一工具栏中线条粗细不一致；图标容器使用稳定尺寸，不因状态切换改变布局
- 播放、上一首、下一首、音量、队列等熟悉控制优先图标表达；不重复附加文字
- 陌生图标、仅图标按钮必须有 tooltip、`aria-label` 和键盘焦点；禁用态不能只靠透明度表达
- 不手画通用 SVG 图标；品牌标识与专属 DSP 可视符号另行设计，不算通用图标体系

### UI-D15 · 组件几何：柔和大圆角（2026-08-30）

- 产品整体使用柔和圆角语言，建立明亮消费产品与 Apple 风格近似的亲和感
- 几何建议：输入/普通按钮 8px；内容面板与 DSP 模块 12px；播放坞、Popover、Sheet、Dialog 14-16px；内容域分段器和少量主动作可用胶囊
- 专辑封面保持 8px 左右克制圆角，不裁成超大圆角或圆形，优先尊重封面艺术
- 大圆角只用于真实表面、分组容器和浮层；歌曲列表行、页面分区、侧栏导航组不逐项套圆角卡片
- 禁止卡片套卡片和玻璃套玻璃；面板内层级优先通过留白、标题、分隔和对齐表达
- 同类型控件必须共享圆角令牌，不能在 6/8/12/16px 间随意漂移

### UI-D16 · 播放层宽屏构图：42/58 + 左对齐歌词（2026-08-30）

- 宽窗口下左侧约 42% 承载方形封面、歌曲名、歌手、音质/来源与少量播放上下文；右侧约 58% 承载逐字歌词
- 歌词采用左对齐的稳定垂直阅读轨道；当前行、前后行和翻译/罗马音不因文本长短改变整体视觉中心
- 封面不能无限放大；超宽屏时内容整体设置最大宽度与合理列间距，避免两区被拉散
- 窄窗口改为上封面、下歌词的纵向结构；播放控制继续由底部播放坞承担，不在正文重复一整套控件
- 歌词区必须允许隐藏翻译、罗马音和逐字动画；关闭后布局平滑重排，不留空列
- 队列/DSP 辅助面板行为由 UI-D46 细化为右侧覆盖式单面板，不重排主构图

### UI-D17 · 动效强度：中等偏流畅 6/10（2026-08-30）

- 动效预算集中于三个签名场景：播放坞连续展开/收起、切歌时封面氛围场交叉过渡、逐字歌词高亮与自动滚动
- 浏览页、侧栏、列表和普通控件只使用 150-250ms 的状态反馈；不做页面滚动入场秀、磁吸按钮、持续粒子、卡片漂浮和无意义流光

### UI-D50 · 首次启动：完整初始化向导（2026-08-30）

### UI-D51 · 初始化向导：可跳过 + 安全默认（2026-08-30）

### UI-D52 · 暗色主题：深石墨体系（2026-08-30）

- 主背景使用深石墨而非纯黑/OLED 黑；建议起点约 `#111318`，表面层级约 `#191C22` / `#22262E`，最终值需实机对比度校准
- 主文字使用柔和近白，避免大面积纯白发光；次级文字保持 WCAG AA，不使用灰上灰低对比
- Hyper Blue 继续承担交互，Pulse Orange 继续承担播放活动；暗色下可使用亮度校正变体，但语义不交换
- 玻璃透明度低于亮色主题并使用更稳定的深色遮罩；禁止大量亮边、霓虹外发光和紫蓝科技渐变
- 展开播放层可根据封面比主界面更暗或更有色彩，但曲库、设置和 DSP 工作台保持稳定深石墨基线
- 暗色不是另一套皮肤：布局、圆角、排版、图标、状态和交互与明亮主题一致
- 强制避免纯 `#000000` 与大面积纯 `#FFFFFF`；Windows 高对比模式完全让位于系统语义色

### UI-D53 · 输入与无障碍：完整桌面键盘优先（2026-08-30）

- 所有核心工作流无需鼠标即可完成：内容域与页面导航、搜索/命令面板、表格选择与多选、上下文菜单、播放控制、队列、DSP、设置和辅助窗口
- 焦点环使用稳定 2px Hyper Blue，任何主题和封面背景下都满足可见性；不为 Apple 风格隐藏 outline
- 图标按钮具备 tooltip、可读名称和明确按下/选中状态；Fill 变体不能是唯一状态提示
- 拖拽排序、面板停靠、队列移动和导航自定义都必须提供键盘菜单/移动命令替代
- 来源、VIP、缓存、版权、播放和错误状态使用文字/图标/形状组合，颜色不作为唯一信号
- 支持 Windows 高对比、系统文本缩放、减少动效、降低透明度和键盘导航；缩放后不裁切关键控件
- 快捷键可查看/修改并检测冲突；不劫持常见文本编辑和系统保留组合
- 屏幕阅读器播报播放状态与任务变化时节流；连续播放进度不得每秒播报造成噪音
- WCAG AA 是最低验收线，正文 4.5:1、大文字与图标 3:1；桌面窗口行为同样纳入可访问性验收

### UI-D54 · 敏感操作：按可恢复性分级确认（2026-08-30）

- 可撤销操作（从队列移除、导航隐藏/排序等）立即执行并显示可操作的 Undo；Undo 有合理时限和键盘入口
- 影响云端但可恢复的操作（取消收藏、移出歌单等）使用轻量确认或立即执行后提供明确恢复动作，具体按接口可逆性决定
- 不可恢复/高风险操作（删除本地文件、永久删除云端歌单/评论、清空缓存、退出并清除凭据）使用明确模态确认
- 确认文案写清对象、数量、范围和后果，不使用“确定吗？”；确认按钮使用具体动词
- 批量操作显示项目数量与部分名称；删除本地文件优先提供“移到回收站”，永久删除作为更深层动作
- 危险操作按钮使用独立 destructive 语义，不占用品牌橙；键盘默认焦点不能落在危险确认按钮
- 后台任务取消若可恢复部分结果，则说明保留/清除 partial 的行为

### UI-D61 · 浮层动效：轻弹簧短过渡（2026-08-30）

- Popover/菜单进入约 150-180ms，使用轻微 `scale(0.98→1)` + opacity；退出快约 20%
- Sheet/停靠面板约 220-280ms，位移不超过 24px；不使用明显 bounce 或多次回弹
- 对话框约 180-220ms，遮罩淡入，内容轻微上移/缩放；危险确认不使用戏剧化动画
- 播放坞展开/收起约 350-450ms，是全应用唯一允许更显著共享元素连续性的过渡
- 列表、按钮、切换器保持 150-250ms 快速反馈；不为每个内容块添加入场动画
- 所有动效采用统一弹簧/缓动令牌，退出短于进入；不得使用默认 linear/ease-in-out 混杂
- 减少动效模式下取消位移、缩放、共享元素和惯性，只保留短淡化或即时切换

### UI-D80 · vGPU 可选可视化层与 telemetry 边界（2026-09-01）

- 采用 `vgpu` 0.3.1 作为主窗口的可选 WebGPU 渲染层；不将 WebGPU 作为播放、DSP 参数编辑或任何核心功能的可用性前提
- 推荐接入范围：B 封面氛围、按需微型波形/频谱、DSP 响应曲线与 FFT/LUFS/peak 仪表、HRTF 的 2D 或克制 2.5D 空间场
- 不用于权威 FFT、LUFS、true peak、HRTF 卷积或其他 DSP 计算；这些结果由 Rust/HSE 产生，vGPU 只消费并渲染
- 迷你播放器和桌面歌词窗口不创建独立 GPU context；保留 DOM/CSS/Canvas2D，避免多 WebView 常驻 GPU 成本
- 所有 WebGPU 场景必须检测 `navigator.gpu`、捕获初始化失败并处理 `GPUDevice.lost`；恢复时销毁旧 context 并重建 surface/pipeline/buffer/texture
- fallback 使用同一份 Rust telemetry，由 Canvas2D/SVG/DOM 渲染；GPU 失败不得影响播放、DSP、缓存或权益判断
- 主窗口只维护一个可重建 `Gpu` context；资源 identity 稳定复用，pipeline 首次显示前预热，DPR 上限 2，隐藏/失焦/节能时降至 15 Hz，减少动效时 2 Hz 静态摘要，未显示时 0 Hz
- visual telemetry 使用独立二进制 Tauri channel，不进入 Zustand 或通用 events。每 WebView 最多一个会话、全局默认最多两个；只允许一个未 ACK 动态帧，积压时覆盖旧帧，永不阻塞 actor/CPAL
- tap 固定命名 `post_dsp_pre_output_gain`，仅分析实际被 `AudioOutput::write` 接受的 active PCM，不分析 standby，不传原始 PCM
- 默认动态帧：64 桶双声道 min/max 波形、96 个对数频谱带、LUFS/peak/true-peak/limiter reduction、epoch/sequence/sample frame/DSP revision；目标小于 1 KiB/frame，默认 30 Hz
- telemetry 不包含曲目 ID、标题、路径、账号、缓存身份、URL、IR 或 HRTF 数据集名；空间状态只发送数值化监听者/声源/房间参数
- 测试分层：`vgpu/mock` 测资源与生命周期、`vgpu check --require-validation` 校验 WGSL、固定 DPR 单帧像素测试验证 shader、真实 Tauri/WebView2 验证 WebGPU/设备丢失/fallback；mock 通过不能代替真实 GPU 验收
- 正式 runtime 依赖尚未加入 `package.json`。接入顺序必须是 Rust telemetry 契约 → Canvas2D fallback → vGPU renderer → WebView2 硬件验收
