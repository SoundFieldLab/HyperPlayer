# 后端补充功能规划（M0–M5 主干之外的缺口盘点）

> 定稿日期：2026-09-05。本文是对 `docs/架构基线.md`（工程事实源）与 `docs/播放器架构.md`（实现规格书）的**补充功能登记**：M0–M5 后端主干（播放引擎 / 本地曲库 / 缓存 / 网易云协议层 / DSP / 任务模型）已完成并全量测试，本文件登记盘点出的 54 项尚未实现或缺失的功能，按域分组并给出优先级与批次建议。
> 状态约定：每项标注【未实现】= 尚无任何实现；【部分】= 有底层能力但业务闭环缺失；【冲突】= 与既有文档决策冲突，需先决策；【M6 已有】= 架构基线 M6 已登记该事项。
> 本文只登记规划，不替代既有决策；实施顺序与决策变更以 `docs/UI定调决策记录.md` 与本文批次为准。

## 一、播放核心（12 项）

| # | 功能 | 状态 | 说明与衔接 |
| :-- | :-- | :-- | :-- |
| 1 | 倍速播放（playbackRate） | 【未实现】 | DualElementSource 元素已暴露 playbackRate 字段（鸭子类型含），但无命令接线/UI 设置/持久化；播客场景需要，变速不变调需评估 HSE 时间伸缩能力（vendor signalsmith-stretch 为可选依赖） |
| 2 | 切歌淡入淡出（crossfade / fade-out） | 【未实现】 | DualElementSource 是"旧元素出声至新曲 canplay 才 swap"的硬切；音量走输出增益（不碰 DSP 参数），需新增 per-element 增益淡变通道或输出增益曲线 |
| 3 | A-B 区间循环 | 【未实现】 | 状态机无 AB_LOOP 事件/状态；需新增循环区间状态 + seek 边界调度（练歌/学乐器场景） |
| 4 | 睡眠定时器（定时停止 / 播完本曲停止） | 【未实现】 | 无调度任务；TaskCenter 任务种类需扩展（timer 类），或独立 SleepTimer 服务 |
| 5 | 单曲播放进度记忆（断点续播） | 【未实现】 | SettingsService 有队列持久化（含当前曲索引与位置，崩溃恢复保持暂停），但无**每首歌 position 持久化**（长音频/播客刚需）；需播放历史表或 settings 内 per-track map |
| 6 | 音频设备热插拔监听 | 【未实现】 | setSinkId + enumerateDevices 已有；缺 `devicechange` 事件监听与"当前设备被拔出自动迁移"策略（UI-D85 语义扩展） |
| 7 | 系统媒体键 / SMTC 集成 | 【M6 已有】 | 架构基线 M6 已登记：依赖现成 Tauri 插件可行性调研，不可行则 v1 缺席并记录；global-shortcut 插件已注册但无"快捷键 → PlayerController 命令"接线 |
| 8 | 全局快捷键自定义 | 【未实现】 | global-shortcut 已注册；缺绑定管理、冲突检测、用户自定义设置项（settings 模型扩展） |
| 9 | 心动模式 / 智能混播 | 【未实现】 | 四态播放模式（顺序/循环/单曲/随机）无网易云式"心动模式"；需推荐 API（playmode/intelligence 路由已有）+ 队列插入策略（喜欢的优先插播） |
| 10 | 私人 FM 播放模式编排 | 【未实现】 | 92 路由含 personal_fm/fm_trash，但 QueueController 双区模型无"FM 无限流模式"（无上下文队列、自动拉取下一首、垃圾桶/不再喜欢） |
| 11 | 歌词翻译（tly）与罗马音（romalrc）轨道 | 【未实现】 | 解析三件套只有 TTML/LRC/YRC 主轨；LyricLine 类型已含 translation/roman/romanWords 字段（waveforge 语义），但 LyricsTimeline 无多轨合并与渲染数据输出 |
| 12 | 歌词时间偏移调整（offset） | 【未实现】 | 无全局/单曲 offset 设置与持久化（settings 扩展 + LyricsTimeline 时间轴平移） |
| 13 | 本地 .lrc 同名文件加载 | 【未实现】 | 扫描器只索引音频；需同目录同名歌词发现与绑定逻辑（LibraryService 扩展） |
| 14 | 本地歌曲的在线歌词匹配 | 【未实现】 | 无"本地 track → 搜索 API → 候选歌词列表 → 用户手动关联 → 持久化绑定"业务流 |
| 15 | 桌面歌词（独立置顶窗口） | 【冲突】 | **UI-D84 已砍除迷你播放器与桌面歌词（v1 不实现）**；未来恢复模型已在架构基线 §10 登记（主窗口唯一状态源、广播只发控制面、辅助窗本地 rAF 自驱插值）——如需立项须先推翻 UI-D84 |
| 16 | 内嵌歌词（USLT/SYLT tag）提取 | 【未实现】 | metadataWorker 解析 tags 但未提取内嵌歌词字段；LyricsTimeline 缺该来源 |
| 17 | 歌词滚动交互后端（positionAt） | 【未实现】 | LyricsTimeline 只有 indexAt(position) 单向查询；点击行跳转需 positionAt(index) 反向查询 |

## 优先级与批次建议

| 优先级 | 条目 | 理由 |
| :-- | :-- | :-- |
| **P0（体验硬伤）** | 7/8 媒体键与快捷键接线、40 单实例、47 Stronghold 正式密码、11 歌词翻译/罗马音、12 歌词 offset、48 本地播放历史 | 没有它们，日常使用会立刻被感知为"残缺" |
