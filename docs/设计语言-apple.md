# HyperPlayer 设计语言（Apple 定调）

> 定调日期：2026-09-05。以 Apple 设计语言（`docs/DESIGN-apple.md` 令牌分析 + WWDC 流体界面原则）为基准的 UI 设计语言基线。
> 保留约束：**Hyper Blue `#3F55F9` 与 Pulse Orange `#FF761C` 双色不变；现有 LOGO 资产不变。**
> 决策记录见 `docs/UI定调决策记录.md` UI-D91~D98。

## 1. 人格总纲

安静、精确、内容优先的专业音频工具。UI chrome 后退，让封面与音乐内容说话：零装饰渐变、chrome 无阴影、单一产品阴影仅给"躺在表面上的内容物"。布局做减法，层级靠留白、字重、表面明度与材质重量建立。

## 2. 色彩令牌

### 亮色

| 令牌 | 值 | 用途 |
|---|---|---|
| `canvas` | `#FFFFFF` | 主内容画布 |
| `parchment` | `#F5F5F7` | 侧栏/分区底、次级表面 |
| `pearl` | `#FAFAFC` | 次级按钮底 |
| `ink` | `#1D1D1F` | 主文字/深色 utility 按钮底 |
| `ink-secondary` | `#6E6E73` | 次级文字 |
| `ink-muted` | `#86868B` | 辅助/禁用文字 |
| `hairline` | `#E0E0E0` | 描边/分隔 |
| `divider-soft` | `rgba(0,0,0,0.04)` | 软分隔 |
| `hyper-blue` | `#3F55F9` | 唯一交互色：链接/CTA/选中/焦点/分段器 |
| `pulse-orange` | `#FF761C` | 播放能量：正在播放/进度高光/DSP 激活/逐字填充 |
| `error` / `success` / `warning` | 独立语义令牌 | 不占用蓝橙 |

### 暗色（取代 UI-D52 深石墨）

| 令牌 | 值 | 用途 |
|---|---|---|
| `canvas` | `#1C1C1E` | 主画布 |
| `elevated` | `#2C2C2E` | 抬升表面/卡片 |
| `tertiary` | `#3A3A3C` | 三级表面/芯片 |
| `text` | `#F5F5F7` | 主文字 |
| `text-secondary` | `rgba(235,235,245,0.6)` | 次级文字 |
| `hairline` | `rgba(255,255,255,0.12)` | 描边 |
| `hyper-blue` | `#5B6CFF`（亮度校正变体） | 交互色，语义不变 |
| `pulse-orange` | `#FF8A3D`（亮度校正变体） | 播放能量，语义不变 |

规则：禁止大面积纯 `#000` / 纯 `#FFF`；高对比模式完全让位系统语义色；蓝不承担语义状态，橙不承担警告/危险；网易云红只表达来源/红心。

## 3. 字体体系（取代 UI-D13）

- **得意黑退出 UI**，仅存在于 LOGO 图片资产。品牌感由排版纪律承载，不靠装饰字体。
- Latin/数字：`Segoe UI Variable, Segoe UI, system-ui, sans-serif`（平台系统字体优先原则）。
- 中文：`Source Han Sans SC`（思源黑体），与 Latin 同字号同字重；fallback `Microsoft YaHei UI`。
- 技术/代码：`Cascadia Mono`（DSP 参数、码率）；时间码/时长用 `font-variant-numeric: tabular-nums` 防跳动。
- 字重只有 400 / 600（无 500、正文不加粗到 700）。

| 层级 | 规格 |
|---|---|
| display | 32px / 1.15 / `-0.02em` / 600 —— 页面主标题、播放层歌曲名 |
| title | 24px / 1.2 / `-0.015em` / 600 —— 分区标题、详情页头部 |
| heading | 17px / 1.3 / 0 / 600 —— 卡片标题、分组标题 |
| body | 14px / 1.47 / 0 / 400 —— 正文、列表、按钮（prose 可升 16px） |
| caption | 12px / 1.35 / `+0.01em` / 400 —— 辅助信息（小字用正字距） |

字号专属字距：大字负字距、小字微正字距、正文 0；行高与字号反向联动。**letter-spacing 永远跟字号绑定，不存在全局固定字距。**

## 4. 圆角与按钮语法（取代 UI-D15 的阶值）

- 圆角三阶：**8px** 控件（按钮/输入/小芯片/专辑封面）、**18px** 卡片与大表面（内容卡/Dialog/Sheet/播放层表面）、**pill** 主动作与胶囊坞/内容域切换器。禁止 8/18/pill 之外的自由值。
- 双按钮语法：**Hyper Blue pill = 主动作 CTA**（每屏至多一个主推）；**8px utility 矩形 = 次级/工具动作**（pearl 底或 ghost）。
- 按下态统一 `scale(0.95~0.97)`；键盘焦点 2px Hyper Blue 焦点环（UI-D53 不变）；悬停只做表面明度微变，不做阴影爬升。
- 危险动作独立 destructive 红，不用橙。

## 5. 材质系统（取代 UI-D59）

- **内容穿底**：主内容延伸到自绘标题栏与侧栏下方；两者为半透明 material，内容从其下滚过。
- 材质参数基线：亮色 chrome `rgba(245,245,247,0.72)` + `blur(20px) saturate(180%)`；暗色 `rgba(28,28,30,0.68)` + `blur(20px) saturate(160%)`；顶缘 1px 高光 `rgba(255,255,255,0.4)`（亮色）模拟材质受光。
- **重量分级**：大表面（侧栏/胶囊坞/播放层遮罩）重 blur + 深阴影；小芯片/浮出控件轻 blur + 浅阴影。大表面阴影 `0 8px 32px rgba(0,0,0,0.12)`，小芯片 `0 2px 8px rgba(0,0,0,0.08)`——浮层之外无阴影。
- **滚动边缘效应**取代 1px 硬分隔线：内容与悬浮 chrome 交界处做 12-16px 模糊渐隐遮罩。
- 玻璃上文字遵循 vibrancy 规则：提高对比、字重 600、微加字距；彩色元素放在实色层上，不直接压玻璃。
- 进出场 **materialize**：blur 半径与 scale 同步动，玻璃是"到达的材料"不是透明度淡入。
- 永不久轻玻璃叠轻玻璃；同一视区最多一层 backdrop blur 内容。
- 降级链：`降低透明度`/`prefers-reduced-transparency` → 不透明实色（层级改用明度差与描边）；`prefers-contrast: more` → 近实色 + 明确描边。

## 6. 动效体系（取代 UI-D61 固定时长主线）

全面采用流体弹簧（Motion 实现），一切动画可中断、从当前呈现值起跳：

| 场景 | 参数 |
|---|---|
| 默认 UI 弹簧（浮层/面板/页面状态） | `bounce 0`（临界阻尼）/ `duration 0.35` |
| momentum 手势（播放层下拖、拖拽停靠、甩动） | `bounce 0.2` / `duration 0.4` + **释放速度交接** |
| pointer-down 反馈 | `scale(0.96)`，100ms 内即时（不等 click） |
| 胶囊坞 ⇄ 播放层共享元素展开 | 弹簧 + 共享布局，唯一允许的大幅连续性过渡 |
| 播放层下拖 | 1:1 跟手 + 橡皮筋边界 + 速度投影落点（`current + (v/1000)·d/(1−d)`，d≈0.998） |
| 进出场路径 | 同路径往返（从哪来回哪去）；Popover/Sheet `transform-origin` 锚定触发元素 |
| 反向过渡 | 镜像缓动（可逆过渡曲线互逆） |

- 手势驱动禁用 CSS transition/keyframes（不可中断）；仅 opacity 类非手势过渡保留 150-200ms 固定时长。
- reduced-motion 降级：位移/缩放/弹簧 → 200ms opacity 交叉淡化；橡皮筋取消；逐字填充改整词高亮。

## 7. 布局语法

- **开放分区**：章节直接铺在画布上，靠标题/留白/对齐建结构（UI-D60 精神不变）。
- **Apple utility-card 语法**：真实实体内容用 18px 卡 + hairline 描边 + 无阴影（首页主推荐、专辑/歌单封面网格、设置分组容器）；禁止卡片套卡片、卡片墙。
- **效率密度并存**：曲库表格 48px 行高、多列状态等效率密度保留（UI-D22/35）；页面级留白按 Apple 节奏放宽（分区间距 ≥48px，卡内边距 20-24px）。
- 封面网格沿用 UI-D39（196-220px 理想尺寸）；艺术家圆形头像沿用 UI-D70。

## 8. 图标与品牌

- **Phosphor Regular/Fill 双态保留**（UI-D14 不变）：SF Symbols 不可分发，Phosphor 是最接近 Apple 克制线型的合法图标族；唯一图标族，禁止混用。
- **LOGO 资产不变**；蓝橙品牌双色语义不变（UI-D11/12）。
- 蓝橙合成渐变禁令保留（UI-D11）；全应用零装饰渐变（Apple 纪律）；启动页蓝橙流动渐变是唯一例外（UI-D87）。
