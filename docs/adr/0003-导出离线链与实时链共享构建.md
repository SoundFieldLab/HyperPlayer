# ADR-0003: 导出 WAV 离线链与实时链共享构建逻辑

`exportToWav` 原本离线渲染时复制粘贴了一套效果链，已与实时链漂移：缺失 presenceMatrix 与 bassPunch 新效果、混响/滤波参数用旧值，导致导出结果与实时听感不一致。决定：**把"依据设置构建效果链"提取为共享的图构建函数，实时链与离线渲染链都调用它**（离线上下文用适配层把 AudioContext 调用映射为 OfflineAudioContext 调用）。

根因是实时链演化（M/S 矩阵、新滤波器）时离线链未同步。共享构建使漂移不可能再次发生；新增效果自动同时出现在实时与导出中。

> **现状注记（2026-09-13）**：离线导出当前由 `exportV3Mp3`（`src/services/HyperSoundEngine-v1/attachV3Engine.ts`，解码 PCM → `EngineV3.process` 分块 → lamejs 128kbps MP3）承担；`exportToWav` 已不存在（`saveWav` 仅剩 `src/electron.d.ts` 的类型声明）。**共享构建原则不变**（实时链与离线导出共用同一 `EngineV3.process` 内核）。
