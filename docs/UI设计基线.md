# HyperPlayer UI 设计基线

> 状态：正式 Tauri UI 实现与验收基线，2026-09-01  
> 来源：`UI定调决策记录.md`（UI-D1~UI-D80）、`UI调研报告/` 三份报告、`DESIGN-apple.md`。  
> 本文件用于约束现行 UI 实现和真实 Tauri 窗口验收。DSP 工作台按产品 D29 的 HSE 完整核心实施，vGPU 可视化遵循 D31 / UI-D80。

## 1. Design Read

面向重度音乐用户的 Windows 桌面播放器。视觉语言是**明亮、柔和、内容优先的消费产品**，同时保留专业音频工具的清晰与效率。Apple 风格只取内容层级、留白、材质克制和连续动效；不仿制 Apple 品牌或 macOS 控件。

设计拨盘：

- Design Variance：6/10
- Motion Intensity：6/10
- Visual Density：7/10

## 2. 产品骨架

```text
┌──────────────────────────────────────────────────────────────┐
│ 自绘标题栏：返回 / 前进 / 页面标题 / 全局搜索 / 窗口控制      │
├───────────────┬──────────────────────────────────────────────┤
│ 品牌          │                                              │
│ 网易云 | 本地 │               主内容区                       │
│               │                                              │
│ 模式导航      │                                              │
│               │                                              │
│ 音效          │                                              │
│ 状态/账号/设置│                                              │
├───────────────┴──────────────────────────────────────────────┤
│ 三段式可展开播放坞                                           │
└──────────────────────────────────────────────────────────────┘
```

- 内容域：网易云模式（默认）与本地模式；切换只改变浏览/导航，不中断队列、播放、DSP 或缓存。
- 默认工作区：聆听预设，无常驻停靠面板。
- 导航：完整侧栏 → 窄窗图标栏 → 展开播放层完全隐藏。
- 窗口：首次 1440×900；重点优化 1920×1080；最小 960×640。
- 历史：网易云/本地各自维护页面栈、滚动、筛选和选中状态。

## 3. 导航与首页

### 网易云模式

默认导航：首页、搜索、音乐库、发现、最近播放。

- 音乐库：喜欢、收藏、账号歌单、云盘。
- 发现：榜单、新歌、MV、DJ/电台。
- 账号页：资料、VIP、等级、关注/粉丝、听歌报告、动态。
- 消息中心：通知与收到的评论。
- 评论跟随具体内容打开，不做一级入口。

导航允许设置中排序、隐藏、显示和固定审核过的二级入口；保留模式切换、至少一个内容入口、音效、当前播放和设置等结构锚点。

首页：继续聆听主推荐（55%）+ 3-4 个最近上下文（45%），随后依次是日推/FM/新歌、歌单、榜单、专辑/频道。匿名用户仍能浏览公开内容，登录按需渐进。

### 本地模式

默认导航：概览、歌曲、专辑、艺术家、文件夹、播放列表。

首页：继续聆听 → 最近新增 → 常听专辑/艺术家 → 本地播放列表 → 扫描/存储状态。空曲库直接引导添加音乐文件夹。

## 4. 播放体验

### 播放坞

三段式，约 76-80px：

- 左：封面、歌曲名、歌手、喜欢、精简来源/权益状态。
- 中：上一首、播放/暂停、下一首；下方进度。
- 右：实际音质、DSP 状态、队列、音量滑杆；设备/独占模式进入音量菜单。

模式按钮单击轮换顺序/列表循环/单曲循环/随机，右键或长按直接选择；智能播放独立于基础四态。

### 展开播放层

- 由播放坞连续展开，不是独立路由。
- 宽屏 42% 左封面/信息，58% 右侧左对齐逐字歌词；窄窗上下布局。
- 背景为当前封面放大、裁切、降采样与强模糊形成的封面氛围场，再覆盖单层克制玻璃遮罩。
- 点击空白、顶部收起按钮、受限下拖或 Esc 分层关闭；返回按钮只管页面历史。
- 队列/DSP 快捷面板从右侧覆盖 360-420px，一次只开一个，不重排歌词。
- 左下角可按需打开约 220×88px 微型波形浮窗；不常驻、不遮歌词。

### 歌词

- 思源黑体；当前行稳定在视区约 42% 高度。
- 当前行 600 字重；前后 2-3 行降低对比度但保持清晰。
- 逐字使用 Pulse Orange 或校正后的封面色做行内填充，不缩放、不弹跳、不改变字宽。
- 翻译在原文下，罗马音再下一级，可分别关闭。
- 手动滚动后暂停自动跟随，用户点击“回到当前歌词”恢复。

### 队列

当前曲 + 两区模型：

1. 接下来播放：手动临时优先项，播完移除。
2. 当前上下文：专辑/歌单/搜索/本地选择产生，可拖拽。

混合来源允许，但每项常驻显示来源、权益、音质和缓存状态。预取优先临时区首项，再到上下文下一曲。

## 5. 可停靠多面板

- 预定义左、右、底部三个槽位。
- 队列、辅助歌词、DSP 快捷等面板可拖动、调尺寸、标签堆叠和脱离为 Tauri 浮动窗口。
- 每槽最多一个主面板，不做无限嵌套 IDE 分割。
- 内置聆听、曲库管理、DSP 调音三套预设；默认聆听。
- 1920px 可多面板并列；1440px 优先标签堆叠；960px 退化为覆盖式单面板。
- 原型只实现预定义槽位真实交互和模拟浮动，正式阶段再接 Tauri 多窗口。

## 6. 视觉令牌方向

### 主题

- 首次明亮。
- 用户可选明亮、深石墨、跟随 Windows。
- 暗色主背景建议从 `#111318` 起校准，表面 `#191C22` / `#22262E`；不用纯黑。

### 品牌色

- Hyper Blue `#3F55F9`：导航、选择、按钮、链接、焦点和确认。
- Pulse Orange `#FF761C`：正在播放、音频活动、DSP 激活与歌词填充。
- 禁止蓝橙通用渐变按钮/标题。
- 网易云红只表示来源/红心/专属语义。

### 动态色

- 默认开启、标准强度；仅用于播放层氛围和首页主推荐。
- 必须校正亮度/饱和度/对比度；失败时回退品牌色。
- 不改变导航、焦点、语义色、列表或 DSP 参数。

### 字体

- 展示/品牌：得意黑（Smiley Sans）。品牌名、页面/分区标题、播放层强调文案、空状态标题。
- 内容/UI/歌词：思源黑体（Source Han Sans SC）。歌曲名、歌手、导航、列表、设置、正文、逐字歌词、翻译和罗马音。
- 技术数据：Cascadia Mono。
- Fallback：Segoe UI Variable / Segoe UI / Microsoft YaHei UI / system-ui / sans-serif。
- 正文 14-16px，辅助最低 12px，主要字重 400/600，letter-spacing 0。

### 图标

Phosphor Icons，Regular 默认，Fill 表达当前播放、收藏、选中等强化状态。单一图标族；陌生图标有 tooltip/aria-label。

### 几何

- 输入/普通按钮：8px。
- 内容面板/DSP 模块：12px。
- 播放坞/Popover/Sheet/Dialog：14-16px。
- 分段器与少量主动作可用胶囊。
- 专辑封面约 8px；艺术家头像始终圆形。
- 禁止卡片套卡片和逐列表行卡片化。

### 材质

- 侧栏和主内容使用稳定不透明表面。
- 玻璃只用于播放坞、Popover、Sheet、浮动面板和播放层遮罩。
- 同一区域最多一层 backdrop blur；不动画 blur。
- 降低透明度/高对比/节能时退化为高不透明实色。

## 7. 内容呈现

- 首页：开放分区 + 少量实体卡片，不做外层模块卡片。
- 封面网格：1440px 4-5 列；1920px 6-7 列；168-220px 自适应，支持小范围缩放。
- 艺术家：所有场景圆形头像；专辑/歌单方形圆角。
- 缺失资产：按实体 ID/hash 生成稳定低饱和几何占位，不联网猜图。
- 专辑/歌单详情：左侧 240-280px 封面，右侧元数据与操作，下方全宽曲目表；滚动后头部收缩。
- 歌曲页/曲目页：表格主列表，48px 行；单击选中、双击播放、Ctrl/Shift 多选、右键菜单、列排序/缩放。
- 状态常驻：1920px 拆分来源/音质/权益/缓存列；1440px 合并状态列；960px 保留标题/歌手/状态/时长。

## 8. 搜索、命令与操作

- 标题栏：返回/前进、简短页面标题、短搜索入口、完全自绘窗口控制。
- `Ctrl+K` 统一搜索；输入 `>` 进入命令模式。
- “全部”搜索按歌曲/专辑/艺术家/歌单/命令分组，组内标注来源；不跨来源自动合并。
- 完整上下文菜单按来源、权限和选择状态生成；右键与更多菜单共享命令定义。
- 可撤销操作立即执行 + Undo；云端可恢复操作轻确认；不可恢复操作明确模态。
- Windows 标题栏需恢复拖拽、双击最大化、系统菜单、Alt+Space、边缘缩放、DPI、多显示器与 Snap Layout；无法可靠恢复时退回原生按钮。

## 9. 设置、账号与系统状态

- 设置：左侧分类，右侧单层表单。分类为外观、播放、音频与 DSP、曲库、缓存、网易云账号、导航与快捷键、系统集成、关于。
- 网易云登录：独立账号页，二维码为主；保留来源页面和待执行动作；Cookie 不进入 UI。
- 匿名状态仍可搜索与浏览公开内容，需要账号能力时渐进登录。
- 状态中心位于侧栏底部，聚合扫描、缓存、同步、更新和问题。
- 加载使用同形 Skeleton；空状态说明原因并给动作；错误局部可恢复；长期任务不刷 Toast。
- 首次启动使用完整向导，但非必要项可跳过并使用安全默认值。
- 后续启动默认进入网易云首页，可改为本地首页或上次稳定页面；恢复队列/进度但默认不自动播放。
- 主窗口首次关闭时询问“最小化到托盘 / 退出”，可记忆选择；正在播放和后台任务的后果必须说明。

## 10. 辅助窗口

### 迷你播放器

约 300×340px 方形封面窗，封面为主，底部歌曲信息、播放三键、进度与音量。可置顶和吸附边缘；不放完整队列/DSP/长歌词。

### 桌面歌词

约 900×150px 双行水平窗，默认底部居中。透明背景，逐字填色；支持单/双行、原文/翻译/罗马音、锁定、点击穿透、置顶、字号/描边/透明度与位置调整。

## 11. 动效

- 总强度 6/10。
- 菜单 150-180ms；面板 220-280ms；对话框 180-220ms；播放坞展开 350-450ms。
- 退出约比进入快 20%；轻弹簧、短距离，无明显 bounce。
- Motion：共享布局、面板、列表、浮层和主题。
- CSS：hover/focus/active。
- vGPU 0.3.1（可选 WebGPU）：仅用于主窗口 B 材质封面氛围、按需微型波形/频谱、DSP 曲线/仪表和 2D/克制 2.5D 空间场；Rust 提供权威有界 telemetry，vGPU 只渲染。
- Canvas2D/SVG/DOM：作为全部 vGPU 场景的生产降级，并继续承担歌词、迷你播放器和桌面歌词；缺少 WebGPU 或设备丢失不得影响播放和参数编辑。
- GPU/Canvas 高频数据不进入 React/Zustand；使用独立 telemetry channel，按需订阅、latest-frame 覆盖和显式 ACK，隐藏/失焦/减少动效时降频或停帧。
- 项目不引入 GSAP；复杂编排由 Motion 时间线、Web Animations API 或专用 GPU/Canvas 渲染器完成。
- 首页禁用 ScrollTrigger 和营销页式滚动表演。
- 减少动效时取消位移、缩放、惯性和共享元素，仅保留即时切换/短淡化。

## 12. 无障碍与国际化

- 完整桌面键盘工作流；拖放和停靠有键盘菜单替代。
- 焦点环稳定 2px Hyper Blue；不为视觉隐藏。
- WCAG AA：正文 4.5:1，大文字/图标 3:1。
- 支持 Windows 高对比、文本缩放、减少动效、降低透明度。
- 屏幕阅读器播报播放/任务变化需节流。
- v1 简体中文；所有文案从首版使用 i18n key，并以长英文伪本地化验证布局。

## 13. 品牌

- 图形标识 + 得意黑 `HyperPlayer` 字标。
- 图形从 H、波形、双轨/双内容域或 DSP 信号路径提炼，不直接使用通用音符、唱片或播放三角。
- 品牌蓝为主体，橙仅作小比例播放脉冲；需适配应用图标、任务栏、托盘、单色和高对比。
- Logo 方案待单独设计与用户确认。

## 14. Tauri 高保真验收计划

所有 UI 变体和交互都在正式 Tauri 2 / WebView2 窗口中运行与验收；不提供独立浏览器预览或运行时 mock bridge。固定测试数据只能作为组件测试 fixture，不得进入生产路由或冒充后端业务结果。

### 第一轮：核心聆听路径，两套视觉变体

- 主窗口框架 + 网易云首页
- 播放坞与展开播放层
- 专辑详情与曲目表格
- 队列预定义槽位停靠/模拟浮动
- 明亮/深石墨双主题

两套变体共用相同信息架构、数据、交互和品牌令牌：

- **A 明亮纯净**：中性表面与留白更强，玻璃更少，突出 Apple 式内容优先
- **B 封面氛围**：封面动态色和悬浮材质更明显，但仍遵守单层玻璃、对比度与性能边界

两套均完整覆盖截图与任务流，不提交“完整 A + 概念 B”。用户逐页选择 A、B 或明确组合规则后再收敛。

### 第二轮：剩余关键页面

- 初始化向导、本地首页、设置、网易云账号页
- 迷你播放器、桌面歌词、状态中心
- Loading/Empty/Error/Confirm 状态样板

### 第三轮：DSP 与可视化

按产品 D29 的 HSE 完整 DSP 核心实施工作台。vGPU 只负责主窗口中的响应曲线、频谱、LUFS/peak 仪表、封面氛围和空间场渲染；所有数值与 DSP 结果来自 Rust。先完成 bounded telemetry 和 Canvas2D/SVG fallback，再接 WebGPU，不制作与后端脱节的假工作台。

### 数据与状态

正式运行只消费 Tauri commands/events 返回的真实数据。缺封面使用按实体 ID/hash 生成的稳定低饱和几何占位；loading/empty/error/unavailable 使用明确状态组件。固定中英日混合数据仅用于单元测试 fixture，不进入生产 bridge、路由或页面。

### 验收

- 真实窗口 Computer Use：点击、键盘、拖放、播放层、主题、缩放和辅助窗口。
- 截图：1440×900 明亮/暗色、1920×1080、960×640。
- 自动检查：控制台、重叠、溢出、焦点、减少动效、降低透明度。
- 设计评审：design-taste-frontend、frontend-design-review、web-design-guidelines。
- 用户逐页最终确认；未确认页面不得冻结令牌或进入正式实现。

## 15. 当前未决

- D29 / UI-D57：HSE 完整 DSP 核心接入后完成工作台实现、parity、性能和真实音频验收。
- D31 / UI-D80：完成 bounded telemetry、Canvas2D fallback、vGPU 主窗口渲染和 WebView2 device-loss 验收。
- 用户逐页确认：真实 Tauri 窗口中的 A/B 材质、双主题、辅助窗口和多尺寸页面仍需最终确认。
- 实测校准：最终颜色、玻璃不透明度、阴影、间距和动效曲线仍按 Tauri 截图与任务流微调。
- 字体与品牌收口：三线 Logo 已作为现行图形源，仍需补单色/高对比/托盘小尺寸验收及内置字体分发许可确认。
