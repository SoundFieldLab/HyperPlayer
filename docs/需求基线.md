# HyperPlayer 需求基线（v1）

> 2026-09-04 现行基线（D1~D35）。桌面架构依据 [ADR-0005](./adr/0005-tauri2-react-rust.md) + [ADR-0006](./adr/0006-webview-playback-ts-services.md)；Rust 曲库边界依据 [ADR-0004](./adr/0004-rust-owns-library.md)。**D34/ADR-0006 重定调前后端边界：播放/DSP/网易云/缓存治理在 WebView TS，Rust 只留曲库与壳；D35 补定前后端八条接缝契约。**

## 产品定位

**现代化 Windows 桌面音乐播放器**；认真开源（Apache-2.0）；差异化武器 = **自研 DSP 音效**；官方内置网易云音源；v1 全功能发布。

## 通信边界（D34 + D35 接缝）

- **前端内部**：播放链、网易云协议、DSP、缓存治理全部在 WebView 内完成，不经 IPC 搬运 PCM/协议数据
- **tauri-plugin-http**：网易云协议与 CDN 播放的统一传输通道（fetch 形状，绕 CORS；**HTTPS 任意域**，D35 Q19 放弃域名白名单；Rust 侧无协议逻辑、无 Cookie 知识；音源可禁用由前端模块边界承担）
- **本地文件**：`asset:` 自定义协议（曲库目录进 scope，TS 经 asset URL 播放/解码）
- **Command（约 46 个，全部无领域知识）**：曲库 CRUD/扫描（24）、settings 哑 KV（2，schema 归 TS）、DPAPI 凭据哑存取（2）、SMTC 转发（3）、窗口/托盘/文件关联/回收站/更新/日志/bootstrap（约 15）
- **Event/Channel**：扫描进度、`media_button_pressed`（媒体键下行）、播放状态跨窗口广播（主窗口权威，进度 1Hz、歌词按行）
- **存储介质**：缓存 = OPFS（用户不可见、钉在应用数据目录随程序走）；配置/DSP 预设 = Rust app-data JSON 哑 KV；Cookie = Rust DPAPI 保险库；曲库 = SQLite（Rust）
- Rust 不再出现：PCM 解码/输出、DSP 算法、网易云协议、权益判定、遥测计算、天气（TS 重做）

## v1 范围

- 本地播放：播放/暂停/切歌/进度/音量、队列；双源 gapless——本地完整数据（本地文件/整轨缓存）AudioBuffer 采样级调度，流式在线播放 MediaElement 近似（预载+快切）；本地格式支持 = WebView2 原生格式集（MP3/FLAC/AAC/OGG/WAV），APE/DSF/DFF 明确不支持
- 曲库：目录扫描、元数据、封面、SQLite 索引（Rust）
- 歌词：LRC/YRC/TTML、翻译/罗马音、逐字时间轴（WaveForge 歌词成套实现）
- DSP：HSE v1.5.1 完整 22 阶段 TS 核心（worklet 实时链）+ HSE2 配置 + 12 预设；DSP 工作台 = HSE MixingStudio UI + HyperPlayer 皮肤
- 在线音源：网易云全能力（vendored 431 端点 + WaveForge 业务层）；115 函数能力域全部进入产品能力候选
- 账号与权益：扫码登录、账号同步、账号本有 VIP/付费权益；服务端返回完整有效 URL 即可播放
- 网易云扩展：歌单/收藏写操作、红心、评论、关注、MV、DJ/FM、云盘、听歌记录、journey/explore 均保留进入产品的可能
- 硬底线：不做 Unblock、跨平台匹配、替代源解灰、伪造 VIP 或篡改权限（unblockneteasemusic 与 song_url_match 路径不引入）；没有官方有效 URL 时停止
- 缓存/离线/导出：不提供音乐文件下载或导出；D30 默认 10 GiB（可配置 2–100 GiB），达到上限清理至 90%，保护最近 100 个不同远程曲目；缓存为应用私有
- VIP 缓存硬规则（D23，TS 执行）：缓存域为 `AccountEntitled(userId)`，只有当前登录同一账号且服务端实时确认 VIP/相应权益有效时才可播放；失败时 fail closed。登出/过期/切号立即锁定缓存，不因文件存在而放行
- 专辑缓存（D24，TS 执行）：专辑上下文播放时始终预取并预热下一曲；同一专辑完成 5 次有效专辑会话后晋升高频专辑，系统空闲时低优先级补齐整张专辑。有效会话 = 从专辑上下文发起且完整播放至少 1 首或累计 5 分钟，同一专辑每日最多计 1 次
- Windows 集成：托盘、SMTC、媒体键、文件关联
- 发布：Tauri bundler、updater plugin、GitHub Releases

## 通信边界

- **Command**：曲库查询、播放控制、设置读写、音源请求等有界请求/响应
- **Event/Channel**：播放状态、进度、扫描进度、长期任务日志等连续通知
- React 不直接读磁盘、数据库或 Cookie，不持有网易云协议密钥
- Tauri 应用层不实现 DSP、曲库规则和音源领域逻辑，只做编排与系统适配
- engine/domain crate 不依赖 Tauri，以便独立测试和未来复用
