# HyperPlayer 需求基线（v1）

> 2026-09-01 现行基线（D1~D31）。桌面架构依据 [ADR-0005](./adr/0005-tauri2-react-rust.md)；Rust 曲库边界依据 [ADR-0004](./adr/0004-rust-owns-library.md)。D13/ADR-0003 的 Electron 方案仅保留为决策史。

## 产品定位

**现代化 Windows 桌面音乐播放器**；认真开源（Apache-2.0）；差异化武器 = **自研 DSP 音效**；官方内置网易云音源；v1 全功能发布。

## 技术栈（现行定案）

```text
┌──────────────────────────────────────┐
│ Web 前端 —— React + TypeScript + Vite │
│ 播放控制 / 曲库 / 歌词 / 主题 / 设置    │
└──────────────────┬───────────────────┘
                   │ Tauri commands（请求/响应）
                   │ events/channel（状态/进度流）
┌──────────────────┴───────────────────┐
│ Tauri 2 Rust 应用层                   │
│ 窗口 / 托盘 / 生命周期 / 权限 / 更新     │
│ 系统集成 / command 编排               │
└──────────────────┬───────────────────┘
                   │ 直接 Rust crate 调用
┌──────────────────┴───────────────────┐
│ hyperplayer-engine（框架无关）         │
│ symphonia 解码 → DSP 管线 → WASAPI    │
│ 曲库扫描 → lofty → rusqlite           │
│ 网易云协议终态（网络/Cookie/加密）      │
└──────────────────────────────────────┘
```

## 通信边界

- **Command**：曲库查询、播放控制、设置读写、音源请求等有界请求/响应
- **Event/Channel**：播放状态、进度、扫描进度、长期任务日志等连续通知
- React 不直接读磁盘、数据库或 Cookie，不持有网易云协议密钥
- Tauri 应用层不实现 DSP、曲库规则和音源领域逻辑，只做编排与系统适配
- engine/domain crate 不依赖 Tauri，以便独立测试和未来复用

## v1 范围

- 本地播放：播放/暂停/切歌/进度/音量、队列、常见格式
- 曲库：目录扫描、元数据、封面、SQLite 索引
- 歌词：LRC/YRC/TTML、翻译/罗马音、逐字时间轴
- DSP：按 D29 接入 HSE v1.5.1 的完整 22 阶段 Rust/TS 核心、参数、预设和 HSE2 配置；HyperPlayer Rust engine 为播放权威，使用自有 UI
- 在线音源：网易云全量 Cleanroom 能力（现有 TS 实现作为 oracle，终态迁入 Rust）；现有 115 个函数原则上全部进入产品能力候选
- 账号与权益：支持扫码登录、账号同步和账号本来拥有的 VIP/付费权益；服务端返回完整有效 URL 即可播放
- 网易云扩展：歌单/收藏写操作、红心、评论、关注、MV、DJ/FM、云盘、听歌记录、journey/explore 均保留进入产品的可能
- 硬底线：不做 Unblock、跨平台匹配、替代源解灰、伪造 VIP 或篡改权限；没有官方有效 URL 时停止
- 缓存/离线/导出：不提供音乐文件下载或导出；D30 默认 10 GiB（可配置 2–100 GiB），达到上限清理至 90%，保护最近 100 个不同远程曲目
- VIP 缓存硬规则（D23）：缓存域为 `AccountEntitled(userId)`，只有当前登录同一账号且服务端实时确认 VIP/相应权益有效时才可播放；失败时 fail closed。登出/过期/切号立即锁定缓存，不因文件存在而放行
- 专辑缓存（D24）：专辑上下文播放时始终预取并预热下一曲；同一专辑完成 5 次有效专辑会话后晋升高频专辑，系统空闲时低优先级补齐整张专辑。有效会话 = 从专辑上下文发起且完整播放至少 1 首或累计 5 分钟，同一专辑每日最多计 1 次
- 全专辑缓存仍是受控缓存，不是下载；只缓存官方 URL，禁止解灰、跨源替代和文件导出。真正 gapless 还需 standby decoder、编码延迟裁剪和 PCM ring buffer
- Windows 集成：托盘、SMTC、媒体键、文件关联
- 发布：Tauri bundler、updater plugin、GitHub Releases

## UI 设计基线（UI-D1~UI-D79）

- **产品骨架**：网易云/本地双内容域，默认网易云；左侧栏顶部双段切换；底部三段式可展开播放坞；播放、队列、DSP 与缓存跨内容域连续
- **主页面**：网易云首页继续聆听优先，本地首页曲库概览优先；开放式章节 + 少量实体卡片；表格主列表 + 自适应封面浏览
- **播放层**：42/58 大封面 + 左对齐逐字歌词；封面氛围场与单层克制玻璃；左下按需微型波形；辅助面板右侧覆盖
- **桌面能力**：有限槽位停靠 + 浮动窗口；完全自绘标题栏；统一搜索/命令面板；完整上下文菜单和键盘工作流
- **窗口**：默认 1440×900，重点优化 1920×1080，最小 960×640；侧栏常驻/收窄/播放层隐藏
- **视觉**：明亮柔和消费产品 + 克制 Apple/Liquid Glass 近似；玻璃只用于悬浮层；明亮默认并提供深石墨/跟随 Windows
- **品牌**：Hyper Blue `#3F55F9` 管交互，Pulse Orange `#FF761C` 管播放；封面动态色默认开启但仅用于播放层和首页主推荐
- **字体与图标**：得意黑展示，思源黑体内容/歌词，Cascadia Mono 数据，系统字体兜底；Phosphor Regular/Fill
- **组件**：Tailwind CSS 4 + 深度定制 shadcn/ui（Radix）；柔和大圆角但禁止无意义卡片化和玻璃嵌套
- **动效与可视化**：总强度 6/10；Motion + CSS 负责产品 UI 与短反馈；vGPU 0.3.1 可用于主窗口封面氛围、按需波形/频谱、DSP 曲线/仪表和空间场，必须保留 Canvas2D/SVG/DOM 降级；Rust/HSE 负责权威分析；不引入 GSAP
- **辅助体验**：完整初始化向导、独立网易云账号页、方形封面迷你播放器、双行水平桌面歌词、侧栏状态中心
- **Tauri-only 验收**：A 明亮纯净/B 封面氛围、其余关键页面和未来 DSP 第三轮均在真实 Tauri/WebView2 窗口中通过 Computer Use、多尺寸截图和设计 skills 验收；浏览器渲染不能作为通过证据
- 完整规则见 `docs/UI设计基线.md`，决策依据见 `docs/UI定调决策记录.md`
