> 定调日期：2026-09-05（UI-D99~D104）。本文是 UI 信息架构的最后一块：页面清单、分段结构、布局模板与关键动线。
> 设计语言见 `docs/设计语言-apple.md`；导航栈机制见 `docs/架构基线.md` §4；冲突时以 `docs/UI定调决策记录.md` 最新条目为准。

## 2. 网易云模式（默认）页面清单

一级导航（侧栏，UI-D7）：**首页 / 搜索 / 音乐库 / 发现 / 最近播放**。

| 页面 | 布局模板 | 内容结构 |
|---|---|---|
| 首页 | 混合页（开放分区） | 主推荐（左 55% 大封面+上下文+继续播放）+ 最近上下文（右 45%）；分区顺序：每日推荐 → 私人 FM → 新歌 → 推荐歌单 → 榜单/频道（UI-D6/D40） |
| 搜索页 | 大标题 + 大输入框 | 空态：历史/热搜/分类浏览；输入后全宽结果分组（歌曲/专辑/歌手/歌单，UI-D33 语义） |
| 音乐库 | 网格页/列表页 + 分段 6 段 | **歌单（默认）｜歌曲（红心）｜专辑｜歌手｜MV｜云盘**；歌单段=我的歌单网格+创建入口；歌曲段=红心歌曲表 |
| 发现 | 混合页 + 分段 5 段 | **榜单（默认）｜新歌｜歌单广场｜MV｜电台**；榜单段=榜单列表+预览 |
| 最近播放 | 列表页 | 单列表按时间分组（今天/昨天/本周/更早），不分段 |
| 歌单详情 | 详情页模板 | 侧置封面头部（UI-D41）+ 全宽曲目表 + 滚动收缩；操作：播放/随机/加入队列/收藏/编辑（按权限） |
| 专辑详情 | 详情页模板 | 同上 + 发行年份/版权/音质信息 + 缓存状态 |
| 歌手详情 | 歌手模板（UI-D102） | 圆形大头像头部 + 动作行（播放热门/加入队列/关注）+ 热门歌曲 TopN+查看全部 + 专辑网格 + MV 行 + 简介 |
| MV 播放页 | 沉浸视频页 | `<video>` 自绘 Apple 风控制条（播放/进度/音量/全屏），无弹幕/无 B 站背景/无清晰度切换 |
| 账号页 | 独立路由（UI-D32） | QR 登录为主 + 登录后资料/VIP/等级/退出 |

## 3. 本地模式页面清单

一级导航（UI-D8）：**概览 / 歌曲 / 专辑 / 艺术家 / 文件夹 / 播放列表**。

| 页面 | 内容结构 |
|---|---|
| 概览 | 继续聆听 → 最近新增 → 常听专辑/艺术家 → 本地播放列表 → 扫描状态（UI-D8 顺序）；空曲库进专用空状态 |
| 歌曲 | 全量表格（UI-D35 响应式列），状态列简化：格式/码率/文件缺失（无 VIP/来源列） |
| 专辑 / 艺术家 | 封面网格（UI-D39/70）→ 详情复用网易云模板去云端能力 |
| 文件夹 | 面包屑 + 子目录卡网格 + 当前层曲目表 |
| 播放列表 | 用户自建列表网格 + 列表详情（UI-D41 模板）；SQLite 持久化 |

## 4. 分段控件语义（UI-D99）

- 用途：**页面内平行子区**切换（音乐库 6 段、发现 5 段）。
- 形态：大标题下方一排浅灰胶囊分段条，选中项白底浮起（Apple Music 风格）；切换用弹簧交叉过渡。
- 状态计入历史栈 entry（`params.segment`），返回/前进/跨域切换均可恢复；每页最多一层分段，不嵌套；分段永不进侧栏。

## 5. 大标题与内容区几何（UI-D104）

- **大标题收缩全页统一**：所有一级页与详情页 32px display 大标题起手；滚动越过阈值收缩为标题栏中央内联标题（UI-D41 扩展），弹簧过渡。
- 内容区水平内边距 32px（960 窗口降 24px）；最大宽度 1680px 居中，表格页允许全宽；分区间距 ≥48px；内容穿底滚动（UI-D95）。
- 标题栏中央标题与大标题互斥显示：展开态显示页面大标题，收起态由标题栏接管。

## 6. 布局模板速查

| 模板 | 适用 | 骨架 |
|---|---|---|
| 列表页 | 歌曲/最近播放 | 大标题 + 工具行（排序/筛选/播放全部）+ 表格 |
| 网格页 | 专辑/歌单/歌手/MV | 大标题 + 分段（如有）+ Apple 卡网格 |
| 详情页 | 专辑/歌单/播放列表 | 侧置封面头部 + 全宽表 + 收缩 |
| 歌手页 | 歌手 | 圆形头像头部 + 热门歌曲 + 专辑网格 + MV 行 |
| 混合页 | 首页/概览/发现 | 开放分区 + 异构节奏（UI-D60） |
| 沉浸页 | 播放层/MV | 全画布，chrome 隐藏/淡出 |

## 7. 关键动线走查

| # | 动线 | 路径 |
|---|---|---|
| 1 | 首次启动 | 启动页 → 初始化向导（可跳过）→ 网易云首页（匿名） |
| 2 | 快速搜索 | `Ctrl+K` / 标题栏入口 → 命令面板（快速结果 + `>` 命令模式）→ Enter 跳转 |
| 3 | 浏览搜索 | 侧栏"搜索" → 搜索页（历史/热搜）→ 输入 → 结果分组 → 详情 → 返回恢复搜索词与滚动 |
| 4 | 播放 | 任意列表双击/Enter → 播放 + 胶囊坞激活 → 点封面 → 播放层 → 队列/波形面板 → Esc 分层退出 |
| 5 | 登录 | 受限动作 → 账号页（QR）→ 成功 → 返回来源并恢复待执行动作（UI-D31/32） |
| 6 | 模式切换 | 双段切换器 → 播放/队列不中断 → 恢复该域离开现场（UI-D1/42） |
| 7 | 缓存管理 | 列表缓存状态图标 → 详情/右键查看 → 状态中心管理任务 |
| 8 | 设置 | 侧栏底部设置 → 分类侧栏 + 单层表单 → DSP 高级项跳音效工作台 |
| 9 | DSP | 侧栏"音效"（跨域固定）→ 工作台；胶囊坞/播放层只显示状态 |
