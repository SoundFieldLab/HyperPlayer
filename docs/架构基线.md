# HyperPlayer 架构基线

> 定调日期：2026-09-05。本文是"产品/栈定调"与"架构定调"两次会话的完整结论，是重建的工程事实源。
> 细化设计（模块/状态机/保险机制）见 `docs/播放器架构.md`；页面地图与动线见 `docs/页面与动线.md`；UI 设计语言见 `docs/设计语言-apple.md`（UI-D91~D98）；UI 层决策以 `docs/UI定调决策记录.md`（含 UI-D81+ 修订条目）为准。

## 1. 总体形态

- **Tauri 2 桌面壳 + 全 TypeScript 应用层**，Windows 首发。
- **壳零自定义 Rust**：只使用官方/社区插件与配置，不编写任何 Rust 代码。
- 插件清单（M0 按需启用）：core（window/event/path）、`dialog`、`fs`、`http`、`store`、`sql`、`stronghold`、`window-state`、`global-shortcut`、`notification`、`updater`、`autostart`。
- 音频/DSP 引擎为 **HyperSoundEngine v1.5.1 纯 TS**（`vendor/HyperSoundEngine-v1.5.1-local`，Rust 支线已删除），经浏览器宿主（AudioWorklet）接入。

## 2. 应用分层

```
src/
  app/            启动页、根组件、Provider 装配
  shell/          自绘标题栏、侧栏、胶囊坞容器、路由容器、主题令牌
  domains/
    player/       AudioEngineController、DualElementSource、HseController、
                  QueueController、LyricsTimeline、TelemetryTap
    netease/      协议服务、会话/凭据、内容 DTO 与缓存
    library/      扫描、元数据、索引查询
    dsp/          音效工作台状态与 HSE 参数模型映射
    settings/     设置模型与持久化
  shared/         UI 原语（shadcn/Radix 重主题化）、工具、类型
```

- **services 为无 React 依赖的单例模块**，持有协议、缓存、业务规则。
- **zustand 切片按域拆分独立文件**（playback/queue/library/netease/settings/ui），禁止单文件巨 store（旧版 768 行单文件 store 的教训）。
- 组件只做两件事：订阅切片、调用服务。

## 3. 状态与数据流

- 状态库 **zustand 域切片**；服务端态缓存沿用 WaveForge `indexedDBCache` + `cacheManager` 模式收进 netease 服务，不引入 TanStack Query。
- **高频态全响应式**：播放进度、逐字索引等以帧级频率进 zustand。
  - 配套纪律（基线强制）：所有订阅使用窄选择器，组件只订阅所需单字段（`position`、`currentWordIndex`…），禁止宽 selector 将帧级更新放大为全树渲染。
- AudioContext **首次播放用户手势时惰性创建**；`visibilitychange`/失焦仅影响可视化刷新率，不影响音频。

## 4. 导航（双内容域历史栈）

- **自研双栈导航切片 navStore**，不使用 react-router。
- 每内容域（网易云/本地）一个 entry 数组 + 指针；entry = `{ routeId, entityId, params, snapshot? }`；分段控件状态计入 `params.segment`（UI-D99）。
- 标题栏返回/前进、`Alt+Left/Right`、导航点击走同一命令集；播放层/停靠面板/命令面板/账号页等瞬时层**不进栈**。
- 滚动位置、选中项、筛选拌入 entry 恢复；历史条目用稳定 routeId + 实体 ID，恢复时显示缓存快照并后台刷新。
- routeId → 组件注册表渲染；无 URL 消费方（桌面应用）。

## 5. 播放链（音频子系统）

```
<audio>A/B 交替 ──► MediaElementSource ──► HSE host 节点 ──► 分析 tap ──► masterGain ──► destination
（解码/流式/seek 交给浏览器）                    （AudioWorklet）
```

- **MediaElement 起步 + PCM 升级闸门**：双 `<audio>` 元素交替实现切歌，接口上抽象"音频源提供者"；M3 后若无缝/预取质量不达标，局部引入 WebCodecs/PCM 管线升级，不推翻结构。
- **音频源提供者两类**：
  - `LocalFileSource`：本地/缓存文件经 `convertFileSrc`（内建 asset 协议，纯配置，需在 assetProtocol scope 声明曲库与缓存目录）。
  - `NeteaseStreamSource`：`<audio>` 直连直链播放（media 元素不受 CORS 限制）；落盘缓存经 tauri-plugin-http 流式拉取 + plugin-fs 分块写，边播边缓存。
- HSE host：`createHyperSoundEngineHost` → `attach({ audioContext, masterGain, analyser })`，标准 AudioNode 图。
- 输出设备：`enumerateDevices` 枚举 + `AudioContext.setSinkId` 即时切换；失败保持原设备并提示。**无独占模式**（UI-D45 修订）。
- QueueController：双区队列（接下来播放/当前上下文）、播放模式四态、随机模式持稳定序列。
- LyricsTimeline：TTML/LRC/YRC 解析（从 waveforge-lyrics 提取 `ttmlParser`/`lyricWordTiming` 等），逐字时间轴驱动歌词渲染。

## 6. 网易云协议层

- `vendor/netease-cloudmusic-api`（431 端点）+ `vendor/waveforge-netease/local-server.mjs` 的 **92 条路由业务逻辑全量移植**进 WebView TS 服务层，作为完整模块搬运适配（axios → tauri-plugin-http，原生层绕 CORS；fs 落盘 → 浏览器存储/stronghold）。
- 保留语义：重试/超时、song/url 音质降级候选循环、付费内容拦截、QR 登录轮询、Cookie 会话管理。
- **行为 oracle**：WaveForge 现网实现对拍，渐进验证（旧 CONTEXT "行为 oracle" 概念沿用）。
- 凭据/Cookie：**tauri-plugin-stronghold** 加密存储；UI 永不展示原始 Cookie。
- 红线：不引入解灰/跨源匹配（`@unblockneteasemusic`、`song_url_match` 路径废除）；AGPL（folia）只可作 temp 只读参考，严禁拷入仓库。

## 7. 本地曲库

- 扫描：tauri-plugin-fs 目录遍历；解析与遍历在 **Web Worker** 中执行，不阻塞 UI。
- 元数据：`music-metadata`（JS）解析标签/封面。
- 索引：**tauri-plugin-sql（SQLite）**，支持筛选/聚合/排序；万首级曲库不卡界面。

## 8. 持久化分层

| 数据 | 存储 |
|---|---|
| 设置/偏好/布局/队列持久化 | tauri-plugin-store（JSON） |
| 本地曲库索引 + 缓存索引 | tauri-plugin-sql（SQLite） |
| 网易云凭据/Cookie | tauri-plugin-stronghold |
| 网易云数据缓存（封面/歌词/列表快照） | IndexedDB（WebView 内建） |
| **音频流落盘缓存（v1 就做）** | app 缓存目录文件 + SQLite cache 表 |

音频流落盘缓存语义（沿袭旧 CONTEXT，数据源改纯 TS）：

- **公共播放缓存**：服务端确认可免费完整播放的官方音频流，不绑定账号；容量上限 + 最近播放淘汰。
- **账号权益缓存**：绑定 `ownerUserId`，每次播放前重新验证账号/权益/权限；登出、切换账号、会员过期 → **锁定缓存**（文件保留、不可播放、优先淘汰）。
- 播放读取：已缓存 → LocalFileSource 本地播放；未缓存 → 直链边播边缓存。
- 高频专辑补全调度可后置于缓存核心之后，不阻塞 v1 缓存主干。

## 9. 可视化 telemetry

- **分析 worklet tap**：独立分析 AudioWorkletNode 接在 HSE 节点之后、输出增益之前（post-DSP pre-output-gain 语义不变）。
- worklet 内计算 64 桶双声道 min/max 波形、频谱带等，`port.postMessage` 发帧；主线程**只取最新帧**（覆盖式，无 ACK 背压）。
- LUFS 来自链内 LufsMeter 处理器结果。
- vGPU 可选渲染层 + Canvas2D fallback 决策沿用；降级规则沿用（失焦 15Hz / 减少动效 2Hz / 未显示 0Hz）。

## 10. 辅助窗口

- **v1 砍除迷你播放器与桌面歌词**（UI-D84）：胶囊坞已承担"常驻小控制面"；上版多窗口实现反复失败（白屏/未跑通）。
- 未来恢复时单独立项，模型为：主窗口唯一状态源，广播只发"控制面"（切歌/行级时间轴/播放状态，行级而非帧级），辅助窗本地 rAF 自驱插值渲染。

## 11. 仓库结构

- **pnpm workspace 多包**：`app/`（主应用）+ `vendor/*` 各自为 workspace 成员（独立 package.json/tsconfig）。
- HSE 以 workspace 包引用，其自带 vitest 可独立跑冻结向量回归。
- netease-cloudmusic-api 做一次性浏览器适配（`HyperPlayer adaptations` 注释标记，不回改上游）。
- waveforge-lyrics / waveforge-netease 定位为**适配源**：逐文件提取进 `src/` 后按 HyperPlayer 令牌改写，不整包打包。

## 13. 里程碑

- **M0 行走骨架**：壳插件配置 + React/Tailwind/shadcn 骨架 + Apple 设计令牌落地（`docs/设计语言-apple.md`）+ 启动页（蓝橙流动渐变）+ 双域导航框架 + 悬浮胶囊坞（半透明 chrome + 内容穿底）+ 流体弹簧动效基座；本地单曲出声、HSE 场景切换可听。
- **M1 本地曲库**：扫描/索引/列表/专辑艺术家页/表格交互（UI-D22/35）。
- **M2 播放层**：42/58 双主角 + 逐字歌词 + 封面氛围场 + 右侧覆盖面板；本地歌词先行。
- **M3 网易云**：api 适配 → 匿名浏览 → QR 登录 → 播放 + 落盘缓存。
- **M4 DSP 工作台**：效果链排序、EQ 曲线编辑、场景/预设、分享串、旁路、A/B、LUFS 分析（基于 HSE 真实清单）。
- **M5 队列/停靠 + 设置 + 状态中心 + 初始化向导**（辅助窗口已砍除）。
- **M6 发布**：SMTC（依赖现成 Tauri 插件可行性调研，不可行则 v1 缺席并记录）、自启、更新、NSIS/MSI 安装包。
- 每个里程碑在真实 Tauri 窗口可运行、可验收后再进入下一步。
