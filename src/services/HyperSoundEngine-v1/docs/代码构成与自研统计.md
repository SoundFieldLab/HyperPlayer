## 5. 结论

1. **"现成"贡献形态**：3 个可选依赖库（LGPL 1 + MIT 2；当前仓库均未安装，代码 0 行计入自研）+ 14 个 MIT/BSD/标准的概念出处（算法与公式）。
2. **自研主体**：**10247 行源码 + 9729 行测试**（2026-09-13 实测）；按模块归类约 57% 属"有出处的移植实现"、
   43% 属"纯自研业务/编排逻辑"（该比例沿用 2026-08 的 5884 行基线口径，仅供量级参考）；
   引擎级功能（链、场景、分享串、切换、空间音频、测试体系）100% 自研。
3. **无第三方代码直接复制**：所有实现均为独立 TypeScript，出处在文件头注释；GPL/AGPL 零引入。
4. 可直接替换的可选项：meyda/signalsmith-stretch/soundtouchjs 未安装时自动回退自研（特征/相位声码器/LGPL 适配层返回 null），依赖仅为增强。
